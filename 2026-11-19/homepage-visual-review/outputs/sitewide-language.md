# 全站延展说明

这套语言的判定标准不是"首页好不好看"，而是：**把首页那个分支雕塑拿掉之后，剩下的东西还能不能撑住一个数据密集的工作台。**

## 一、需要覆盖的页面类型（按 `web/src/presentation/screens/` 实际存在）

| 类型 | 现有页面 |
| --- | --- |
| 营销页 | `landing/`（唯一允许出现 display 级字号与编辑层的地方） |
| 总览 / 仪表 | `workspace/today-workspace-screen`（分组任务 + 热力图 + 详情侧栏）、`repository/repository-overview-screen`（分支摘要、进度组、mini 热力图、提交时间线） |
| 高密度列表 | `repository/repository-tasks-screen`（分支 tabs + 筛选侧栏 + 任务表格 + 行内操作） |
| 详情 / 编辑 | `task-detail-panel`、`task-detail-slideout`、`task-form-panel`、`new-task-panel`、`complete-commit-panel`、`new-branch-dialog`、`workspace-task-form-drawer` |
| 时间线 / 提交历史 | `commit-timeline-card`、`insights/activity-tab`、`commit-detail-card` |

## 二、可移植内核（五条）

1. **层级只由明度、线宽、字阶承担。** 全站唯一允许的"光"是首页合并节点；进入应用后它退化为面板顶边的 1px 受光边。任何页面不得用阴影或辉光表达层级。
2. **一个母题：1px 线。** 首页是实体发丝；区块头是全宽细线；列表是行分隔线；分支树是连接线；提交历史是脊线；输入聚焦是 1px 亮边。六种尺度，同一种元素。
3. **只存在三档线宽**：0.75px（卡内分隔）、1px（默认，所有边框与分隔）、1.5px（强调：选中/聚焦）。永不出现 2px 以上。
4. **只有两个表面层级**：画布与面板，1px 边框分隔。浮层允许第三层，但只换底色，不叠阴影（白底稿例外：全页只允许一个向下的软阴影）。
5. **强调色只表示位置与状态，不做装饰。** 一行绿 = 一行激活；一个绿点 = 一个状态。这样即使页面上有 300 行，绿色仍然可读。

## 三、逐类页面的退化规则

### 1. 高密度列表（分支树 + 任务表格）

| | |
| --- | --- |
| 保留 | 1px 线母题（行线 = 首页发丝的最小尺度）、唯一强调色、明度层级、2px 圆角 |
| 收缩 | 标题 148→40（页级）/28（区级）；页边距 96→24；雕塑→树连接线（1px，`#232724`）；节点光→6px 方点；section 间距 96→48 |
| 新增 | 40px 行高（紧凑 36）；行 hover = 4% 白；选中行 = 6% 白 + 1px 绿左沿；表头 36px 粘性 + 底部 1px；列间用 1px 竖线，不加斑马纹 |
| 禁用 | 卡片包行、行内彩色药丸、每行阴影、超过一个实心按钮 |

### 2. 详情 / 编辑（表单）

| | |
| --- | --- |
| 保留 | 1px 全框输入、2px 圆角、唯一实心提交按钮、七档字阶 |
| 收缩 | 面板头部 36px；表单区最大 640px；label 12px + 控件文字 15px；控件高 40px（移动端 44px） |
| 校验 | 错误 = 1px danger 边框 + 下方 4px 处 12px 文案；聚焦 = 1px 强调边框 + 2px 外偏移的 12% 环（不用模糊光晕）；不加红底、不抖动、不用 toast 顶替 |
| 禁用 | 浮动 label、阴影输入框、pill 形按钮、错误时整块变红 |
| 容器 | 侧滑 480px 与内联面板共用同一套头部（36px + 1px 线 + 右上关闭），不出现两种弹层语言 |

### 3. 时间线 / 提交历史

| | |
| --- | --- |
| 保留 | 1px 脊线（首页发丝的直系后代）、mono 数据、单一绿色 |
| 收缩 | 脊线 1px `#232724`；节点 7px 方形；hash 11px mono；时间 12px；分支分叉用 1px 斜线，不用曲线 |
| 新增 | 整行 40px 可点；展开区以 1px 上边线开启；同分支连续提交用 16px 缩进而非嵌套卡片 |
| 禁用 | 每条提交一张卡、大号彩色圆点、相对时间胶囊、时间线两侧都放内容 |

### 4. 空 / 加载 / 错误

- **空**：48px 线条分支符号（1px stroke）+ 20px 标题 + 13px 说明 + 一个文字 CTA；空状态是全站**唯一**允许把实心按钮降级为文字链的地方。
- **加载**：1px 不定进度线（160px 宽），不用 spinner；骨架用 3% 白条，不做 shimmer。
- **错误**：行内 = 左侧 1px danger 竖条 + 13px 文案；页面级 = 居中 320px 列，标题 20px。
- **禁用**：插画、emoji、彩色插画、把错误塞进 toast。

### 5. 弹窗 / 浮层 / 命令面板

- **弹窗**：560px 宽、3px 圆角、1px 边框、遮罩 60% 黑（不做 backdrop-blur）。深色版头部用 1px 分隔线；白底版头部用 36px 实心墨条 —— 与产品卡片同一规格。
- **浮层**（下拉、菜单、popover）：与面板同底 + 1px 边框 + 4px 偏移；深色版无阴影，白底版用全页唯一的那一个软阴影。
- **命令面板**：640px；输入行 44px；结果行 36px；快捷键 chip 用 1px 描边而非填充。
- **禁用**：毛玻璃、16px 大圆角、全屏渐变遮罩。

### 6. 移动端

- 行高与控件 44px；底栏 56px + 1px 顶线；页边距 16px；树缩进 12px；面板全宽、无圆角、无阴影。
- **保留**：线母题、单一绿、字阶前五档（40/28/20/15/13）。
- **收缩**：分支雕塑只保留"单干 → 一次分叉 → 节点"三段，删掉上弧、测量网格与编号；首页标题降到 40/32。
- **禁用**：横向滚动展示多栏（直接纵向堆叠）。

| 文字 4 档 | `#F2F3EE` / `#B9BFB9` / `#7C837D` / `#4E544F` | 主 / 次 / 辅 / 禁用 |

### 共用规格

| 项 | 规定 |
| --- | --- |
| 字阶 | display 148/156、96（仅营销）→ H1 40 → H2 28 → H3 20 → body 17（营销）/15（应用）→ 13 → 12 → mono 11/12 |
| 行高 | display 0.88–0.90；40/28 用 1.15；20 用 1.35；15/17 用 1.5；12 用 1.4 |
| 间距 | 4px 基线：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64；页边距 24（应用）、72–96（营销）；行高 40（紧凑 36）；移动 44 |
| 线宽 | 0.75 / 1 / 1.5；永不 >1.5 |
| 圆角 | 2（控件）/ 3（面板、弹窗）/ 0（营销 CTA）/ 999 仅用于 6px 状态点 |
| 表面 | 全哑光；hover 4% 白（白底为 4% 墨）、active 6%、selected 6% + 1px 强调左沿 |
| 聚焦 | 1px 强调边框 + 2px 外偏移的 12% 环；不用模糊光晕 |
| 动效 | 120ms 微反馈、200ms 常规、320ms 每页一次编排；缓动 `cubic-bezier(.2,0,0,1)` 进、`cubic-bezier(.4,0,1,1)` 出；无弹簧、无回弹；无限循环只允许出现在落地页节点（2.4s），应用内禁止 |

## 五、提示词里为延展性写死的约束

以下几条不是修辞，是硬约束；删掉任何一条，这套语言就只能在首页成立：

1. **"Hierarchy is carried by value, stroke weight and type scale only — never by glow, blur or drop shadow."** 否则密集页只能靠辉光分层，必然回到旧版。
2. **"Exactly one light source; in UI it degrades to a single 1px lit top edge."** 给面板一套不依赖阴影的抬升语言。
3. **"One structural motif: a 1px line… same element at six scales."** 保证树、表格、时间线、输入框是同一个语族。
4. **"Two surface tiers only."** 防止密集页变成卡片汤。
5. **"One accent appears strictly as position or state."** 保证 300 行数据里绿色仍然有信息量。
6. **"Controls 36–40px, 2px radius, 1px border, one solid action per screen."** 让营销页的按钮尺寸能直接长进应用界面。
7. **"Display sizes are marketing only."** 防止 148px 泄进应用页头。
8. **"Semantic colors always as a 6px dot plus text, never a filled chip."** 单点色体系里，语义色只能做标记，不能做面积。

## 六、这套语言凭什么在密集页还有冲击力

- **对比不靠留白，靠"黑块 + 细线 + 大字号"三件套的可缩放组合。** 首页的黑块是 156px 标题，应用页的黑块是反白表头 / 选中行 / 主按钮；首页的细线是雕塑，应用页的细线是行网格。同一套东西，尺度不同。
- **一处高光原则。** 每个屏幕只允许一个"最亮的东西"，首页是节点，任务页是当前选中行，设置页是当前分段。眼睛永远知道先看哪里。
- **密度本身成为质感。** 40px 行 + 1px 线 + 12/13px 字，排得越密越像工程图纸 —— 这与首页的"制图稿"气质是同一种，而不是两种。
