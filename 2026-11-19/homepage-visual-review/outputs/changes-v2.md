# 第二版：深色升级 + 白底稿

针对首轮出图（`c3a581a6…_image.png`）的判定：方向成立，但线条是 4–6px 均匀霓虹管、两弧夹角被抹平、两个实心白胶囊互抢焦点、右上死黑、面板偏灰且内部字过小。以下两版均为"结构级"改动，不是调参。

## 一、深色升级版（`prompt-dark-v2-architecture.txt`）

### 相对上一版改了 6 处

1. **线条：霓虹管 → 蚀刻发丝 + 光衰减。** 4–6px 均匀发光改为 0.75–1px、哑光阳极氧化质感；线本身不发光，只在距节点 25% 的区段被照出薄荷高光，其余衰减为 12% 白再没入黑。解决"整条线一样亮、像霓虹灯管"。
2. **分叉几何：加一个"透镜"。** 单干走到 x=33% 处劈开，上、下两条悬索弧张开到 26% 画高的最大间距（x=54%），再在 x=71%/38% 收束进节点。解决"两弧夹角被抹平、读不出分叉→汇聚"。
3. **全画面只留一个发光体。** 删除轨道环、原子环、镜头光斑和第二处辉光；顶栏胶囊按钮直接取消，全页唯一实心元素是文字链 CTA。解决"顶栏胶囊与主 CTA 抢焦点"。
4. **构图切割：62/38 非对称 + 类型与结构互咬。** 标题从 116px 提到 148px，第二行越过产品窗左缘；上弧以 10% 不透明度从标题最后一行背后穿过。解决"标题和主视觉各占一块、互不相干"。
5. **死黑区变成制图稿。** 右上象限保留空白，但压入 3% 白的 96px 工程测量网格（只裁在该象限）与一个 480px、2% 白的"01"，节点正好压在其字怀上。解决"右上大片死黑"。
6. **材质三件套 + 面板改写。** 哑光黑板（底）/ 拉丝钛（节点座圈）/ 0.75px 蚀刻线（结构）；面板从半透明玻璃改为 #0A0B0A 哑光板，只保留顶边一段 45% 长的镜面高光 + 6px 玻璃反光条；内部只两栏、字号 12–15px。解决"面板发灰、字小、三栏并列"。

### 关键色值

底 `#08090A` / 文字 `#F2F3EE` / 次级 `#8B918B` / 薄荷 `#6BFFA0` / 面板边框 `#2B2F2C`

## 二、白底版（`prompt-light-v1-paper-ink.txt`）

不是反色，是另一套语言：**纸与墨**。

### 相对深色版换了 5 件事

1. **底色换成暖纸白 `#F4F1E9`**（不用纯白），加 4% 纸纤维颗粒；纯白会把所有线条和绿色都洗掉。
2. **绿色从电光薄荷 `#5BFF9E` 换成墨绿 `#0E5B37`**，只出现在标题两字、合并节点、一个激活方块。电光绿在纸白上会直接消失。
3. **发丝线从"自发光"变成"绘图仪墨线"**：1.25px `#161815` + 0.6px 浅核 `#3A3D38` 模拟笔槽，远弧 45% 透视为景深；节点改为实心墨绿圆 + 3px 纸白挖空环，无任何辉光。
4. **产品面板改为"白纸卡片 + 墨条"**：`#FBFAF6` 卡面、1px `#161815` 描边、3px 近直角、只有向下 24px 的单向极轻阴影；顶部加一条 36px 实心墨条作为页面上唯一的深色块。
5. **冲击力改由排版与留白承担**：156px/800 中文标题本身就是一块黑体量，配 10px 等宽小标签形成 15 倍尺度比；一条贯穿全高的 1px 栏目线 + 标题第二行越线；副文案以下留大片空纸，不放卡片、不放图标、不放 logo 墙。

### 关键色值

纸 `#F4F1E9` / 墨 `#101210` / 次级 `#4A5049` / 细线 `#C9C6BC` / 卡面 `#FBFAF6` / 墨绿 `#0E5B37`

## 三、出图注意

- 两份都要求 16:10、1512×950、单张平面稿；中文标题原样保留。
- 若中文出糊字：先把标题行换成英文占位（`Fork your goals. Commit your progress.`）重出，拿构图后再在设计工具里排真中文；不要为了文字正确牺牲构图。
- 深色版不要喂首轮出图当参考（会把 4–6px 霓虹管带回来）；白底版同理，最多取构图参考、强度 ≤20%。
- 落地时需自托管中文显示字体（MiSans / 阿里巴巴普惠体 / 思源黑体），当前 `web/index.html` 只有 IBM Plex Sans 与 JetBrains Mono。
