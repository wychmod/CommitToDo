## A. 开发者工具 / AI 编码（5）

### 1. Linear — https://linear.app/
**实拍**：`refs/en-linear.jpg`（首屏在无头浏览器里为纯黑，疑似视频/Canvas；以下依据滚动 700px 后的稳定版面）
- 整页只用一个"产品界面"当主视觉：一块带 1px 描边的深色应用窗，内部是 12–13px 的真实工单流，右侧再浮一块详情面板，形成"界面叠界面"的纵深。
- 强调色只有一个（橙），且只出现在状态点与选中项上，界面本身几乎全灰。
- 品牌墙用一排等距 logo + 一行 10px 大写等宽说明收尾，不加卡片。

**可直接借鉴**：产品窗的"1px 边框 + 2px 圆角 + 单色状态点"三件套——这正是我们 40px 行高表格的现成做法。
**不要抄**：把整块 UI 缩到 12px 以下当装饰（不可读）；以及引入第二个强调色（我们只有绿）。

### 2. Vercel — https://vercel.com/
**实拍**：`refs/en-vercel.jpg`
- 画面只有一个发光几何体（黑色三角锥 + 背后的柔光核），是全站唯一光源。
- 左侧两行 64px 级标题，右侧三行 13px 无衬线说明，中间大片纯黑——用"文字—空—物体"的三段关系制造张力，而不是居中堆叠。
- 底部一排灰度 logo 压住页面下沿，不抢焦点。

**可直接借鉴**：**单光源 + 一个几何主体 + 右侧三行小字**的构图骨架；我们的合并节点就是这颗"光核"。
**不要抄**：三个小胶囊按钮并排（我们每屏只允许一个实心动作）；以及底部 logo 墙（本产品没有客户可展示）。

### 3. Cursor — https://cursor.com/
**实拍**：`refs/en-cursor.jpg`（中文界面，标题"Cursor 是您的编程智能体…"）
- 产品窗浮在一层暖褐色、油画质感的背景上，靠"哑光材质 vs 玻璃界面"的对比把窗口推出来，而不是靠阴影。
- 窗口内部再浮一个 CLI 小窗，两个层级都用 1px 边框区分，没有一处用模糊。
- 中英混排时，中文副标题与英文 UI 各自用各自字体，不加额外分隔。

**可直接借鉴**：**材质对比代替阴影**——面板坐在"有肌理的场"上，而不是坐在灰色底上。
**不要抄**：胶囊按钮 + 圆角 999 的下载按钮；以及把三个窗格硬塞进一张图里，导致内部文字全部小于 11px。

### 4. Resend — https://resend.com/
**实拍**：`refs/en-resend.jpg`
- 黑底上一道极缓的斜向柔光扫过整个画布，是页面唯一的"环境事件"，没有第二处光。
- 标题用衬线体（约 96px），副文案只有两行 15px，密度极低。
- 徽标胶囊 + 两个按钮，全部压到同一水平线上，重心极稳。

**可直接借鉴**：**一道斜向柔光当背景**——比星尘、比渐变块都便宜，且不会抢主体。
**不要抄**：衬线标题（我们的体系是几何无衬线，换字会破坏整套字阶）；以及 pill 徽标。

### 5. Stripe Press — https://stripe.press/
**实拍**：`refs/en-stripe-press.jpg`
- 横向"书脊"长条：一排衬线书名缓缓横向排列，每个书名后跟小号大写的 "(hardcover)"，形成印刷目录的节奏。
- 下方一张 1px 细框包住的油画封面，四角是 10px 等宽大写标签（`[+] NOMAD LETTERS` / `OPEN BOOK [+]`），像展签。
- 黑底 + 单张图像 + 全大写等宽角标，没有卡片、没有图标。

**可直接借鉴**：**1px 画框 + 四角等宽大写角标**——这套标注语言可以直接搬到我们的产品窗与长图分节上。
**不要抄**：整屏依赖一张高成本艺术画（我们没有这类图像资产，也不该引入插画）。

## B. 中文语境（4）

### 6. TRAE — https://www.trae.ai/
**实拍**：`refs/cn-trae.jpg`
- 首屏是一整片点阵粒子场（由点聚成图像），是全页唯一视觉事件。
- 标题压在左下角，两行、约 56px，第一行灰、第二行 `TRAE` 纯白——用明度差代替字号差。
- 右上角一枚**直角**薄荷绿实心按钮，是全页唯一的彩色面积；导航全灰。

**可直接借鉴**：**"灰第一行 + 白第二行"的标题明度分层**，以及直角单色实心按钮（我们已有，但值得确认不做圆角）。
**不要抄**：点阵粒子场——它正是我们判定为"通用科技感"而否掉的东西；也不要把标题压在底部而不给首屏一个明确的视觉主体。

### 7. 语雀 — https://www.yuque.com/
**实拍**：`refs/cn-yuque.jpg`
- 中文标题用极重字重（约 900）堆到 88px 左右，两行"文档协同／知识管理"，字面几乎顶满左栏。
- 右侧是完整产品窗（左导航 + 文档列表），窗口有明显圆角与轻阴影。
- 两个按钮：亮绿实心 + 白底描边，等宽并排。

**可直接借鉴**：**中文用 800–900 字重做巨标题**——汉字在重字重下才有"体量"，这是深色版标题成立的前提。
**不要抄**：亮绿 `#00B96B` 一类品牌绿（浅底上会显得廉价）+ 大圆角 + 阴影卡片三件套，正是浅色稿最容易掉进的 SaaS 模板。

### 8. 少数派 — https://sspai.com/
**实拍**：`refs/cn-sspai.jpg`
- 中文编辑型密度：左栏导航、中栏标题流、右栏推荐，三栏比例约 1:3:1.2。
- 列表项用"标题两行 + 12px 元信息"的固定节奏，行间距大于字号，读起来不挤。
- 深色底上以图片块承担色彩，文字区几乎全灰白。

**可直接借鉴**：**列表的"标题两行 + 12px 元信息 + 大行距"节奏**，可直接用于我们的任务/提交列表。
**不要抄**：彩色卡片马赛克与 16px 圆角——密集页一旦上卡片，1px 线体系立刻失效。

### 9. Manus — https://manus.im/
**实拍**：`refs/cn-manus.jpg`
- 极简到只剩：顶部一排 12px 导航、居中的一块视频、一个 16px 圆角的大输入框。
- 全页只有一个黑色实心按钮（登录），其余全是描边或纯文字。
- 白底不是纯白，是略带灰的暖白，输入框靠 1px 极浅描边与极轻阴影浮起。

**可直接借鉴**：**"整页只有一个实心动作"** 的克制程度，可以直接作为我们的验收标准。
**不要抄**：这套留白属于"无需解释的消费级产品"；我们的首页必须解释"分支／提交"，照搬会变成空页面。

## C. 一句话结论

- 深色版最该临摹的三张：**Vercel 的单光源构图**、**Linear 的产品窗三件套**、**Stripe Press 的 1px 画框 + 等宽角标**。
- 白底版最该临摹的两张：**语雀的中文重字重标题**、**Manus 的单一实心动作**。
- 明确不要碰的三样：Trae 的点阵粒子、少数派的彩色卡片马赛克、Cursor 的胶囊按钮。

## D. 核验说明

- 全部 9 站均于 2026-11-19 用无头 Chrome（1440×900，headless=new）实际打开并截图，截图为当次首屏或指定滚动位置。
- Linear 首屏在无头环境渲染为纯黑（推测为视频/Canvas 首屏），因此其描述基于滚动 700px 后的稳定版面；这一点已标注，未凭记忆补写首屏。
- 所有截图存于 `outputs/refs/`，可作为出图时的构图参考（建议只取骨架，不取配色）。

# E. 大型站（8 个，2026-11-19 实拍）

筛选口径与 A/B 不同：这里选的是"体量大、品牌成熟、官网本身是行业标杆"的站。**但大站的说服力大多来自三样我们没有的东西——品牌资产、海量内容、视频/3D 资源。** 所以每条都单列一栏"在我们这里会失效的部分"。

### E1. Apple — https://www.apple.com/ — `refs/big-apple.jpg`
- 导航实测 **44px 高**、底色 `rgba(29,29,31,.8)`（深色半透明压场）；首屏是 4 块等宽产品摄影拼贴，往下接一条 **34px/50、字重 600、字距 -0.374px** 的促销带；按钮 44px 高、980px 圆角（全圆）。
- 页面总高 5885px，但每屏只讲一个产品。

**可直接借鉴**：导航"**44px 高 + 0.8 不透明深底**"的轻压场处理——我们的 64px 顶栏可以借"滚过首屏才从透明变实底"这一条。
**不要照抄**：4 块摄影拼贴。没有 4 组产品图，它就是 4 个空框。
**失效点**：它靠高成本产品摄影 + 3D 渲染撑首屏，我们一处素材都没有；5885px 的背后是整条产品线。

### E2. Stripe — https://stripe.com/ — `refs/big-stripe.jpg`
- 导航 **76px**、几乎全透明；h1 **48/55.2、字距 -0.96px**，标题后半段用**渐变文字**填色；右上一道柔和多色光带；主按钮 4px 圆角、主色 `#533AFD`；页面 **14572px**，全页铺约 80px 间距的 1px 垂直细网格（间距为目测，未精确测量）。
- 网格线从首屏一直贯穿到页脚，是整页唯一的"结构装饰"。

**可直接借鉴**：**贯穿整页的 1px 垂直细网格**——和我们"制图稿"的语言同族，可以直接做全站底层网格（白底版尤其成立）。
**不要照抄**：渐变文字 + 多彩光带。小体量站点上，它只会变成"AI 味"装饰。
**失效点**：14572px 的深度靠客户 logo 墙、交易额数据、开发者文档支撑；我们既无客户也无规模数据，拉长只会变空。

### E3. Figma — https://www.figma.com/ — `refs/big-figma.jpg`
- 导航 **78px 纯白**；h1 **56/56、字距 -1.25px、字重 400**；右侧三块产品截图**错位层叠**（像一叠画布），每层用 1px 边框区分；主按钮 46px 高、8px 圆角；页面 8760px。
- 没有一处阴影，层级全靠"错位 + 描边"。

**可直接借鉴**：**"错位层叠 + 1px 描边"代替三栏并排**——我们只有一块产品窗时，可以用"主窗 + 后移 24px 的次层"制造纵深。
**不要照抄**：三张不同产品的截图。我们只有一个界面，堆三次会露馅。
**失效点**：它靠 Figma / FigJam / Make 多条产品线与真实画布内容；单产品撑不起层叠。

### E4. Microsoft — https://www.microsoft.com/zh-cn/ — `refs/big-microsoft.jpg`（**首屏视频/轮播在无头环境未渲染，本图为滚动 420px 后的版面**）
- 标题实测 **62/72、字重 500、字距 -1.55px**；下方 6 个"线性图标 + 12px 标签"的等距快捷入口；再往下是 4 张 **16px 圆角**卡片，缩略图为粉彩渐变，促销用色块标签（"热销"）。
- 卡片内文字 16px 标题 + 13px 说明，行距宽松。

**可直接借鉴**：快捷入口的"**线性图标 + 12px 标签**"等距排列——可用在我们的分支/视图切换，比纯文字 tab 更清楚。
**不要照抄**：卡片网格 + 色块促销标签。这是电商目录语言，不是工具语言。
**失效点**：7290px 靠产品目录与促销活动填充；我们只有一条产品线，照搬会空。

### E5. 小米 — https://www.mi.com/ — `refs/big-mi.jpg`
- 导航 **65px**、透明压在满幅汽车照片上；"YU7" 巨字直接排进照片，人物遮住笔画；底部一条 **1px 轮播进度线**（约 1200px 长，橙色激活段约占 1/5）；页面 6858px。
- 全站字体 `MiSans`（与我们建议的中文显示字体同源）。

**可直接借鉴**：**底部 1px 轮播进度线**——比圆点分页克制得多，可直接替换现有分页指示。
**不要照抄**：满幅明星 + 车辆摄影，以及"巨字被人像遮挡"的处理。
**失效点**：完全依赖广告级拍摄与代言人；没有素材时，这一屏只剩一块空图。

### E6. 华为 — https://consumer.huawei.com/cn/ — `refs/big-huawei.jpg`
- 导航 **58px**、透明；首屏是一束紫色四向光束（X 形）铺满整屏，居中白字标题 + 日期 + 白描边按钮（h1 被站方隐藏为 "CN"，**正文字号未测**）。
- 页面 8623px，首屏之后是常规的"图 + 一段文案"交替。

**可直接借鉴**：**"一个光源铺满首屏 + 居中白字"的取舍**——证明一个光事件就够，不需要粒子。
**不要照抄**：3D 光束渲染 + 居中对称构图。我们的语言是左对齐、不对称。
**失效点**：它靠一支 3D 品牌影片；我们只能做 1px 线构成的光形，质感不在一个量级，必须承认。

### E7. 阿里云 — https://www.aliyun.com/ — `refs/big-aliyun.jpg`
- 导航 **64px**、半透明白 `rgba(255,255,255,.7)`；h1 **52/72、字重 600**，关键词用渐变；主按钮 **52px 高、8px 圆角、`#1366EC`**；首屏下方是 4 列"图标 + 标题 + 12px 说明"的入口阵列；页面 **10553px**；正文 `Microsoft YaHei`。
- 一个首屏同时承担搜索、促销、产品入口三件事。

**可直接借鉴**：**"图标 24px + 标题 16px + 说明 12px"的三级入口密度**——可用于我们的空状态引导（不超过 4 个入口）。
**不要照抄**：数百个产品入口 + 顶部搜索。密度是它的资产，对我们是灾难。
**失效点**：10553px 靠 200+ 产品与文档支撑，我们没有这个目录。

### E8. 飞书 — https://www.feishu.cn/ — `refs/big-feishu.jpg`（**首屏被活动弹窗遮挡；描述基于弹窗后方可见版面**）
- 双栏：左文案 + 右产品窗，背景为粉彩渐变网格；黑色胶囊主 CTA + 白底描边次 CTA；页面 **9433px**；实测 h1 为 **38/46、字重 700**，但该 h1 是顶部活动条，不是主标题（主标题字号**未测**）。
- 产品窗内部是真实文档/项目界面，缩略后仍可辨认栏目。

**可直接借鉴**：**粉彩渐变底上放"白底产品窗 + 1px 边框"**——与我们白底稿的纸白卡片同构，只是把渐变换成纸纹。
**不要照抄**：胶囊按钮 + 3D 图标 + 活动弹窗，三者叠加正是"大厂官网味"的来源。
**失效点**：它靠多产品生态（文档/表格/项目/妙记）+ 3D 渲染；单产品撑不起这面"生态墙"。
