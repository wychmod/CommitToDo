# M07 里程碑（MVP）

## 1. 背景与目标

提交记录「做过什么」，里程碑标记「走到哪」。它允许用户在任何分支上钉一个锚点，日期可以只到年月，用于那些说不清具体哪天、但确实发生过的节点。

目标：用户能从历程或分支详情新建里程碑，只填标题和日期（可选备注），在时间树上看到它，并在详情中读到备注；里程碑不影响提交统计与停滞判定。

## 2. 范围与非目标

**范围**

- F-04 里程碑：创建、树上显示、备注；可挂在根分支或任意分支；日期可只到年月。
- S04-milestone-new 新建视图、S04-milestone-detail 详情视图。
- P04 时间树的里程碑节点、P03 分支详情的里程碑行。
- 里程碑对徽章触发事件的产生（展示与发放由 M11/V1-05 负责）。

**非目标**

- 不做里程碑编辑与删除（里程碑永存；是否允许改备注见未决问题）。
- 不做照片、附件、关联待办、提醒。
- 不做年轮与分享图中的里程碑排版（V1-02 / V1-03）。
- 不改表结构；只使用 `milestones` 现有字段。

## 3. 用户故事与主流程

**故事 1｜给今天钉一个锚点**

在历程页点「加里程碑」→ 选择分支（默认当前筛选分支或根分支）→ 填标题「搬进新家」→ 日期默认今天，精度「日」→ 可选备注 → 保存 → 时间树出现菱形节点，分支详情里程碑行出现该条。

**故事 2｜只记得月份**

新建时把精度切到「月」→ 只选「2026 年 11 月」→ 保存 → 树上对齐到 11 月列，不显示具体日；分支详情与详情页都显示「2026 年 11 月」，任何地方都不补一个虚构的日。

**故事 3｜回填过去**

新建时把日期选到三年前 → 保存 → 里程碑出现在对应时间位置；不产生提交，不影响该分支的 `ownLastCommitAt`，也不解除停滞虚线。

**故事 4｜读备注**

在树上点击里程碑节点 → 打开 S04 详情 → 看到标题、日期（按精度）、所属分支路径、备注、创建时间。

**异常与边界**

- 标题为空：保存不可用，提示必填。
- 未选择分支：默认根分支「我」，允许保存。
- 目标分支已归档、已合并或已放下：不可选，写明原因；根分支始终可选。
- 未来日期：MVP 只允许今天或过去；未来日期是否开放见未决问题。
- 同月多个「月」精度里程碑：都对齐到该月列，按创建顺序排列，不互相覆盖；点开簇或列表可分别进入详情。
- 保存失败：保留表单与已选日期精度，提示可重试。
- 重复标题：允许，不要求唯一。
- 分支被收尾后：已创建的里程碑仍显示在父分支历程中，来源按原分支标注；不随合并改写 `milestones.branchId`。

## 4. 界面与交互

### 4.1 新建（S04-milestone-new）

| 字段 | 规则 |
| --- | --- |
| 所属分支 | 默认当前分支或根分支；可选根与进行中分支；不可选已归档/已合并/已放下分支并写明原因 |
| 标题 | 必填，单行 |
| 日期 | 必填；默认今天；可选今天或过去 |
| 精度 | 「日」/「月」二选一；选「月」时只选年月 |
| 备注 | 可选，多行；保存后只读 |

- 入口：P04 历程页「加里程碑」、P03 分支详情里程碑行「新建」。
- 从分支详情进入时预填该分支；从历程进入时预填当前筛选的分支，未筛选则根分支。
- 保存成功后关闭面板，返回来源页面并高亮新节点；不跳转到无关页面。

### 4.2 详情（S04-milestone-detail）

- 展示：标题、日期（按精度渲染）、所属分支路径、备注、创建时间。
- 不提供编辑、删除按钮；备注为空时显示「没有备注」，不显示空标题。
- 从时间树、分支详情、搜索结果（V1）进入同一详情。

### 4.3 树上与分支详情

- 时间树：里程碑为菱形节点，与提交节点视觉区分；`day` 精度按具体日定位，`month` 精度对齐到月份列（R6）。
- 分支详情：里程碑行只显示日期与标题，不展开备注。
- 里程碑不计入提交数、不改变进度、不影响停滞。

### 4.4 五种状态

| 状态 | 表现 |
| --- | --- |
| 空 | 分支详情无里程碑：「新建里程碑」；历程筛选后无节点：按 M06 空态处理 |
| 加载 | 表单与详情保留骨架；树上节点后到，不阻塞其他节点 |
| 错误 | 保存失败保留输入与精度；详情读取失败说明 + 重试 |
| 只读 | 已归档分支的里程碑详情只读；新建时该分支不可选 |
| 无权限或未登录 | 不适用；MVP 无账号 |

### 4.5 移动端

- 新建与详情为全屏面板；日期选择不依赖悬停；精度切换用两个显式选项。
- 月份精度在窄屏仍显示「2026 年 11 月」，不因空间不足补日或截断年份。

## 5. 数据与规则

| 表 | 字段 | 用途 |
| --- | --- | --- |
| `milestones` | `_id`、`branchId`、`title`、`note`、`achievedAt`、`datePrecision`、`createdAt`、`updatedAt` | 创建、详情、树上定位 |
| `branches` | `_id`、`parentId`、`path`、`status`、`archivedAt` | 分支选择与路径展示 |
| `events` | `entityType='milestone'`、`action='create'`、`payload`、`at` | 创建留痕、徽章触发依据 |

规则：

- R6 日期精度：`datePrecision` 只有 `day` / `month`；`month` 只显示年月，不显示具体日；时间树对齐到月份列；不新增 `year` 精度。
- 存储：`achievedAt` 为必填时间；`month` 精度取该月 1 日作为排序与定位代表值（展示不带日）。该归一化的最终写法待技术线写入 0.12。
- 里程碑与提交完全独立：不生成 `commits`，不改 `ownLastCommitAt`，不解除停滞虚线，不计入四计数与周/月/年统计。
- 可挂根分支；根分支的里程碑在根泳道显示。
- 永存：不提供删除；编辑是否开放见未决问题。
- 徽章事件：首次里程碑、累计 3 个里程碑、里程碑带备注分别产生触发事件，供 M11（首批）与 V1-05（完整徽章）消费；本 PRD 不定义徽章展示。

## 6. 验收标准

1. 从历程页新建里程碑，选择分支、填标题、日期默认今天、精度「日」，保存后树上出现菱形节点，分支详情里程碑行同步出现。
2. 精度选「月」并只选年月，保存后树上对齐到该月列，分支详情与详情页均显示「2026 年 11 月」，任何界面不出现具体日。
3. 同月创建两个「月」精度里程碑，两者都保留，按创建顺序排列，均可点开详情。
4. 创建一条日期为三年前的里程碑，出现在对应时间位置；该分支的 `ownLastCommitAt`、提交数、进度与停滞天数均不变。
5. 标题为空时保存不可用；未选分支时默认根分支并可保存；重复标题可保存。
6. 目标分支已归档、已合并或已放下时不可选，界面写明原因；根分支始终可选。
7. 从分支详情进入新建，所属分支预填该分支；保存后返回分支详情并高亮该里程碑。
8. 详情显示标题、按精度渲染的日期、所属分支路径、备注与创建时间；备注为空时显示「没有备注」。
9. 保存失败时表单、日期与精度保留，可重试；不生成半成品节点。
10. 已归档分支的里程碑详情只读；新建入口不提供该分支选项。
11. 390 px 下新建与详情为可关闭的全屏面板，月份精度不补日、不截断年份。

## 7. 依赖与阶段、未决问题

- 阶段：MVP。
- 依赖：M04（分支详情入口与里程碑行）、M06（时间树节点与月份列）。
- 后续消费：M11 首批徽章（立碑 / 三碑 / 碑上有字）、V1-02 年轮、V1-03 分享图、V1-04 搜索、V1-07 回填过去。
- 冲突与处理：
  - `PAGE-DATA-CROSSCHECK` 曾提到 `datePrecision=year`，0.12 与 R6 只定义 `day` / `month`；本 PRD 不支持「年」精度。
  - 画稿与文档未定义里程碑编辑与删除，按「永存」只做创建与查看。
- 未决问题：
  - `month` 精度的 `achievedAt` 归一化（当月 1 日 00:00 或月首本地零点）需技术线写入 0.12。
  - 是否允许未来日期、是否允许修改备注，均未定义；当前只允许今天或过去，且不提供编辑。
  - 同月月精度里程碑在树上的聚合方式未定，当前按创建顺序并排或聚簇。
