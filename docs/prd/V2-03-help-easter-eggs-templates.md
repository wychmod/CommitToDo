# V2-03 帮助、彩蛋徽章与分支模板（V2）

## 1. 背景与目标

三件事放在同一份 PRD，是因为它们都只在 V2 出现，并且都服务于「让用户更久地留下来」：帮助回答规则疑问，彩蛋奖励长期使用中的偶然，模板降低空树时的第一步成本。

本 PRD 交付 I-03 帮助与常见问题、H-06 五枚彩蛋徽章、B-03 四个分支模板，以及 S06-help 视图。

目标：用户能在「我的 → 帮助」找到五条规则问题的明确答案；长期使用中撞见彩蛋，获得后才显示；空树时能从四个模板之一建出一棵不超过 7 个节点、4 条待办的树，并能一键撤回。

## 2. 范围与非目标

**范围**

- I-03 帮助：规则说明 + 常见问题，FAQ 形式，五个固定主题。
- H-06 彩蛋徽章：夜航、跨年、空白年、复活、满月 5 枚，累计 21 枚；获得后显示。
- B-03 分支模板：健身 / 读书 / 求职 / 副业 4 个；仅在空树时出现；每个 ≤1 个一级 + 2 个二级 + 4 条待办；可一键全删。
- S06-help 视图；徽章墙新增「彩蛋」分类；P02 空树入口。

**非目标**

- 不做设计理念、产品故事、版本更新日志。
- 不做帮助搜索、客服工单、反馈表单、社区问答。
- 不做「生日」徽章（需生日字段，另议）；不做彩蛋预告、进度、条件说明。
- 不做模板自定义、模板另存、模板分享、模板市场。
- 不做模板生成提交、里程碑或徽章。
- 不新增表；模板为常量，彩蛋沿用 `badges`。

## 3. 用户故事与主流程

**故事 1｜查「为什么不建第 4 层」**

`/me` →「帮助」→ S06-help 列出五个问题 → 点第一条 → 展开答案：三层是产品的硬约束，第四层会让分支树变成文件树，回顾与泳道也会失真；给「回分支树」与「看三层示例」的入口。

**故事 2｜换设备前查怎么办**

帮助中点「换设备怎么办」→ 答案区分两种情况：同一账号用同步（V2-02），没有账号用「导出 / 异地备份 + 从文件恢复」（M10 / V1-06）；给出对应入口。

**故事 3｜连续三晚完成待办，撞见夜航**

连续 3 天在 23:00–5:00 完成待办 → 第 3 天今天页底部出现轻提示「解锁一枚彩蛋」→「我的」徽章墙出现「彩蛋」分类与「夜航」；获得前，徽章墙不显示这枚徽章的名称与条件。

**故事 4｜空树时用模板开始**

新工作区 `/branches` 只有根分支 → 空态出现「从模板开始」→ 选择「读书」→ 预览显示 1 个一级、2 个二级、4 条待办 → 点「使用这个模板」→ 树与待办生成，模板入口消失。

**故事 5｜模板不合适，一键撤回**

使用模板后没有任何提交 → 空态或模板提示条提供「撤回模板」→ 一次确认，说明会删除模板生成的分支与未完成待办 → 确认后树回到只有根分支，模板入口重新出现。

**异常与边界**

- 帮助内容读取失败：显示说明与重试；不显示空白页。
- 帮助内容与规则冲突：以 `UI-PAGES` 与 `TECH-ARCHITECTURE` 为准，帮助只做解释；文案不得写出与 R1–R19 相反的规则。
- 彩蛋获得前：徽章墙不显示名称、条件、灰点与进度；获得后才出现。
- 彩蛋与既有 16 枚同日获得：今天页轻提示合并为一条「解锁 N 枚徽章」，徽章墙与历程标记按 V1-05 合并显示。
- 「空白年」不能在当年判定：只在次年 1 月 1 日之后回看上一年；应用未打开时，下次进入补查。
- 「满月」在月末最后一天结束前不判定；次月 1 日之后补查。
- 「复活」只对已放下分支判定：该分支重新开始后，若距本分支上一条有效提交 ≥90 天又有有效提交则触发；不含根分支，不看后代；首次提交不触发。
- 撤销提交不收回彩蛋；原事件撤销时按 V1-05 标注「原事件已撤销」。
- 模板只在空树时出现：已有非根分支、待办或提交时入口隐藏；直接访问不存在的模板入口回到 P02。
- 模板生成失败：不产生半棵树；本机数据不变，提示重试。
- 模板生成后已有提交：不允许一键全删，按钮置灰并说明「已产生提交，请按收尾 / 删除处理」。
- 用户修改过模板生成的分支名或新增待办：一键全删仍删除整棵模板子树，确认文案必须写明会连带删除用户新增内容。
- 一键全删失败：树与待办保持原样，提示重试。

## 4. 界面与交互

对应视图：**S06-help**；页面：**P06「我的」**、**P02** 空树。

### 4.1 帮助与常见问题（S06-help）

- 入口：P06「帮助」。
- 固定五个主题，顺序固定：

| # | 问题 | 必须回答的内容 |
| --- | --- | --- |
| 1 | 为什么不建第 4 层 | 三层是硬约束；更深会让树变成文件树、回顾与泳道失真；给「回分支树」入口 |
| 2 | 为什么停滞是 30 天 | 停滞是提醒不是惩罚；超过 30 天在历程用虚线表达；给「去历程」入口 |
| 3 | 为什么提交跨天不能改 | 提交绑定完成当天；当天可改摘要，次日锁定；纠错通过撤销与重新完成；给「看提交详情」入口 |
| 4 | 合并后数据还在吗 | 提交与里程碑保留；子分支历史可见；待办按收尾选择移动到父分支或保持完成；给「去历程」入口 |
| 5 | 换设备怎么办 | 有账号用同步；无账号用导出 / 异地备份 + 从文件恢复；分别给同步与数据页入口 |

- FAQ 为展开 / 收起列表，默认全部收起；可同时展开多条。
- 内容只解释规则，不写设计理念、不放长文、不写版本计划。
- 每条的入口在未登录或未启用对应能力时，仍可跳转到本机页面；不显示不可用按钮。

### 4.2 彩蛋徽章（H-06）

- 在 V1 的 16 枚目录后追加 5 项，`category='easter'`；徽章墙新增「彩蛋」分类。
- 获得前：徽章墙不显示该分类、名称、条件与灰点；帮助与设置也不预告。
- 获得后：进入「彩蛋」分类，按 `grantedAt` 倒序；卡片只显示名称、获得日期与一句来源；详情与 V1-05 一致，但不再展示获得条件。
- 判定条件：

| 名称 | 条件 | 判定时点 |
| --- | --- | --- |
| 夜航 | 连续 3 个自然日，每天都有至少 1 条在 23:00–5:00 完成的有效提交 | 每次完成待办后 |
| 跨年 | 12 月 31 日或 1 月 1 日有至少 1 条有效提交 | 每次完成待办后 |
| 空白年 | 某个已结束自然年恰好只有 1 条有效提交 | 次年 1 月 1 日之后，首次进入或补查 |
| 复活 | 某条已放下分支重新开始后，距本分支上一条有效提交 ≥90 天又有有效提交 | 每次完成待办后 |
| 满月 | 某个已结束自然月每天都有至少 1 条有效提交 | 次月 1 日之后，首次进入或补查 |

- 「夜航」按完成时刻的本地时间判断，跨天按自然日；三天不需要连续在同一周。
- 「复活」只作用于已放下分支，不包含根分支、不看后代；分支必须此前已有有效提交。
- 「空白年」「满月」只对已结束的周期判定，避免当年、当月提前授予。
- 彩蛋不进入徽章墙的「接近达成」逻辑，不显示差距。
- 获得通知沿用 V1-05：今天页底部轻提示，不弹窗、不打断。

### 4.3 分支模板（B-03）

- 入口：P02 空树时的空态「从模板开始」；模板入口仅在没有任何非根分支、待办与提交时出现。
- 选择模板后先预览：显示一级分支名、两个二级分支名、四条待办标题与归属。
- 预览底部两个动作：「使用这个模板」「换一个」。
- 使用后：创建 1 个一级、2 个二级、4 条待办；一级与二级同名规则遵循 M02；待办 `dueDate` 为空，进入「无截止日期」组。
- 模板生成后，P02 空态被正常树替代；在无提交前显示一条可关闭的提示条「模板已创建 · 撤回」。
- 撤回：确认后删除模板生成的分支与待办，回到只有根分支的状态；模板入口重新出现。
- 四个模板的结构上限一致，不允许生成第 4 层、里程碑、提交或徽章。

### 4.4 五种状态

| 状态 | 表现 |
| --- | --- |
| 空 | 帮助无内容：说明 + 重试；模板：非空树不显示入口；彩蛋：未获得不显示分类 |
| 加载 | 帮助展开即时；模板预览即时；生成与撤回显示进度，不整屏 spinner |
| 错误 | 帮助读取失败：说明 + 重试；模板生成或撤回失败：原数据不变，提示重试 |
| 只读 | 帮助只读；模板预览只读；彩蛋与徽章不可编辑、不可删除 |
| 无权限或未登录 | 不适用；帮助与模板不要求登录；彩蛋按本机数据判定，登录不改变已有徽章 |

### 4.5 移动端

- 390 px：帮助为单列手风琴；每条答案内的跳转按钮可点区域不小于 44 px。
- 模板预览为全屏面板，结构预览纵向缩进显示；「使用这个模板」固定在底部。
- 徽章墙「彩蛋」分类与 V1-05 一致，单列卡片；未获得时不显示。

## 5. 数据与规则

| 表 | 字段 | 用途 |
| --- | --- | --- |
| `branches` | `_id`、`parentId`、`path`、`depth`、`title`、`order`、`status`、`archivedAt`、`createdAt` | 模板生成与撤回；空树判定 |
| `tasks` | `_id`、`branchId`、`title`、`status`、`dueDate`、`order`、`createdAt` | 模板生成的待办 |
| `commits` | `_id`、`branchId`、`date`、`at`、`voidedAt` | 彩蛋判定 |
| `badges` | `catalogId`、`category`、`periodKey`、`grantedAt`、`snapshot` | 5 枚彩蛋 |
| 常量 | 帮助文案、四个模板定义 | 只读内容，不落表 |

规则：

- 帮助：五个主题固定；文案与 R1–R19 一致；不写与 `UI-PAGES` 冲突的入口或页面。
- 彩蛋目录：在 V1 的 16 项后追加 `night-flight`、`cross-year`、`blank-year`、`revival`、`full-moon` 五项，`category='easter'`，`periodKey='all'`；17–21 共 5 枚，累计 21。
- 彩蛋判定只算 `voidedAt == null` 的有效提交；判定时点按上表；同一枚只授一次。
- 「空白年」「满月」以本地自然年 / 自然月与业务日期 `date` 为准；已结束才判定。
- 彩蛋快照记录触发事件、事件日期、涉及的年份或月份、分支；不记录待办标题与备注。
- 彩蛋获得前不进入任何界面；获得后遵守 V1-05 的详情、树标记与不可撤销规则。
- 模板常量：健身 / 读书 / 求职 / 副业；每个 1 个一级 + 2 个二级 + 4 条待办；不生成第 3 级、里程碑、提交。
- 模板生成：同一事务内创建全部分支与待办，任一步失败全部回滚；四计数按 R7 更新；不触发徽章（无提交、无子分支收尾）。
- 空树判定：只有根分支，且没有待办、提交、里程碑；示例树不算真实数据。
- 一键全删：仅当模板生成的分支子树没有有效提交与里程碑时可用；删除范围为该子树及其待办；有提交或里程碑时不可用并说明。
- 模板撤回不写 `events` 以外的统计，不触发徽章，不改变设置。
- 具体模板文案与待办标题属于内容定稿，不改变结构上限与交互。

## 6. 验收标准

1. `/me` 点「帮助」进入 S06-help，五个主题按固定顺序显示，默认全部收起；展开与收起可同时操作多条。
2. 五个答案均覆盖 §4.1 表中「必须回答的内容」，且不出现与 R1–R19 相反的规则；每条入口可跳转到对应本机页面。
3. 未登录时帮助中的同步、备份入口仍可点击；同步入口落到 O07 登录提示，备份入口落到 `/data`。
4. 彩蛋获得前，徽章墙没有「彩蛋」分类，也不出现 5 枚徽章的名称、条件、灰点或进度。
5. 连续 3 个自然日在 23:00–5:00 各完成 1 条待办后获得「夜航」；中断一天不获得。
6. 在 12 月 31 日或 1 月 1 日完成 1 条待办后获得「跨年」；其他日期不获得。
7. 某已结束自然年恰好 1 条有效提交，次年首次进入时获得「空白年」；当年不提前授予；0 条或 2 条不获得。
8. 某已放下分支重新开始后，距本分支上一条有效提交 90 天完成待办，获得「复活」；间隔 89 天不获得；未放下分支即使间隔 ≥90 天也不获得；根分支不获得；首次提交不触发。
9. 某已结束自然月每天都有至少 1 条有效提交，次月 1 日之后获得「满月」；缺任意一天不获得；当月不提前授予。
10. 获得任一枚彩蛋后，徽章墙出现「彩蛋」分类，只显示已获得的彩蛋；未获得的仍不显示。
11. 彩蛋与既有徽章同日获得时，今天页只出现一条合并提示；历程该日只出现一个徽章标记，展开后列出全部名称。
12. 空树时 P02 出现「从模板开始」；选择「读书」预览显示 1 个一级、2 个二级、4 条待办；使用后树与待办生成，模板入口消失。
13. 模板生成后待办进入「无截止日期」组，分支 `taskTotal` 增加 4；树中没有第 3 级、里程碑与提交。
14. 已有非根分支、待办或提交时，模板入口不出现；直接访问模板地址回到 P02。
15. 模板生成后没有提交时，「撤回模板」可用；确认后树回到只有根分支、4 条待办删除，模板入口重新出现。
16. 模板生成后产生过有效提交，「撤回模板」不可用并说明原因；树与提交保持不变。
17. 用户修改过模板分支名或新增待办后撤回，确认文案写明会连带删除，确认后整棵模板子树被删除。
18. 模拟模板生成失败：不产生半棵树，本机数据不变，可重试；模拟撤回失败：树与待办保持原样。
19. 390 px 下帮助单列可展开，模板预览为全屏且底部按钮可见，彩蛋分类单列显示。

## 7. 依赖与阶段、未决问题

- 阶段：V2。
- 依赖：V1-05（徽章机制、徽章墙、树上标记）、M02（三层约束与同名规则）、M03（待办写入与无截止分组）、M12（空工作区与示例隔离）。
- 后续消费：无；帮助文案随功能变化更新，但不改变结构。
- 冲突与处理：
  - `FRAMEWORK` H-06 写「累计 21 枚」，「生日」待账号体系落地后另议；本 PRD 只实现 5 枚，不实现生日。
  - V1-05 写「目录固定 16 项」；V2 在其后追加 5 项，V1 的 16 项与判定不变，徽章墙新增分类。
  - `FRAMEWORK` H-03 写「V2 彩蛋仅在获得后显示」；本 PRD 进一步明确：未获得时不显示分类、名称、条件与灰点。
  - `FRAMEWORK` B-03 未写模板生成后已产生提交时能否全删；本 PRD 定为不可全删，避免抹掉历史。
- 未决问题：
  - 四个模板的具体分支名、待办标题与顺序属于内容定稿，当前只固定结构上限与生成规则。
  - 已定：「复活」只作用于已放下分支，不含根、不含后代，按本分支自己的有效提交计算；90 天阈值不变。
  - 「空白年」「满月」的补查频率与跨年时区边界需与 V2-02 的补查机制对齐。
  - 帮助内容是否需要版本号或「最后更新」时间，当前不显示。

最值钱的回归用例有两个。第一个是 `easter-egg.test.ts` 的「同一枚彩蛋只授予一次，且空白年 / 满月只对已结束周期判定」，它守的是每次完成待办都重复写 `badges`，以及当年 / 当月提前授予。手工验收通常只在跨年或月末点一次，很难连续三天在 23:00–5:00 复现「重复授予」，也容易漏掉 23:00 与 5:00 边界，只有把时钟与提交列表传入纯函数才能稳定断言。

第二个是 `template-transaction.test.ts` 的「生成中途失败不留半棵树」，它守的是分支已写入、待办没写完时界面出现一棵残缺模板树。手工点「使用这个模板」几乎不会失败，只有注入写入异常才看得到；而失败后用户会以为模板已完整生成，后续按收尾或删除处理又对不上。

### 8.3 只能人工验收

1. **帮助五条文案与 R1–R19 的一致性**：前置为打开 S06-help；逐条展开并与 R1–R19 对照；判定为五个问题顺序固定、答案覆盖 §4.1「必须回答的内容」、不出现相反规则、每条入口可跳转；1440 与 390。为什么不能进单测：文案语义是否正确需要人读，单测只能断言结构，无法判断「说法与规则一致」。
2. **彩蛋获得前的不可见性**：前置为新工作区、0 枚彩蛋；查看徽章墙、帮助、设置与搜索；判定为没有「彩蛋」分类、名称、条件、灰点与进度，任何位置都搜不到；1440。为什么不能进单测：这是跨多页面的「不存在」断言，需要逐页真实渲染确认。
3. **彩蛋轻提示与同日合并**：前置为制造彩蛋与既有徽章同日获得；完成最后一条待办；判定为今天页底部只出现一条「解锁 N 枚徽章」，不弹窗、不打断，历程该日只有一个标记且展开列出全部名称；1440 与 390。为什么不能进单测：提示位置、动效与不打断体验必须真实渲染。
4. **跨真实自然日与补查**：前置为前一日、前一月数据已就绪；次日或次月 1 日首次进入；判定为空白年与满月只在周期结束后授予，1 月 1 日能同时正确判定跨年与空白年；1440。为什么不能进单测：真实自然日跨越与系统时间无法在单测中等待。
5. **模板入口的真实显隐**：前置为已有非根分支或提交；打开 P02，再直接访问模板地址；判定为入口不出现、地址回到 P02；无提交空树时入口出现；1440 与 390。为什么不能进单测：显隐同时依赖数据状态与路由，需真实页面确认。
6. **模板预览与 390 px 底部按钮**：前置为 390 px 空树；选择「读书」并打开预览、上下滚动；判定为全屏面板、结构纵向缩进、「使用这个模板」固定可见、触控区不小于 44 px；390。为什么不能进单测：布局与固定定位是像素结果。
7. **撤回确认文案与连带删除**：前置为修改过模板分支名并新增待办；点撤回模板；判定为确认文案写明会连带删除用户新增内容，确认后整棵模板子树被删除、模板入口重新出现；1440。为什么不能进单测：确认文案语义与一次确认的交互只能人工判断。
