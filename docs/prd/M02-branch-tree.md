# M02 分支树与分支编辑（MVP）

## 1. 背景与目标

分支是产品唯一的结构容器。本 PRD 交付一棵可读、可建、可改、可移动的单根三层树，让用户在不建项目的前提下把生活面、方向和具体目标放进同一棵树。

目标：用户能在 30 秒内新建一条一级分支，并在同一棵树上完成改名、移动、加子分支；所有结构操作在写入前给出可读的不可用原因，写入后树、额度和路径一致。

## 2. 范围与非目标

**范围**

- D-01 分支树：单根、最多三层、可展开折叠、按一级分支分组、默认展开 L1/L2、L3 折叠。
- D-03 新建、改名、移动子分支：层级、同级重名、额度、状态、循环引用校验。
- K-03 分支配色：7 个预设色相，子分支继承父色相并按层级变浅，不给自由取色，所有视图一致。
- P02 分支树页；B01 行尾操作菜单、B02 新建一级分支、B03 新建子分支、B04 重命名、B05 移动分支。
- 根分支「我」的自动存在与不可删除、不可合并、不可放下。

**非目标**

- 不做收尾、删除空分支（M08）；不做放下、手动归档、取消归档、重新开始（V1-01）；不做排序与置顶（V1-08）。
- 不做分支详情页（M04）。
- 不改表结构，不新增字段；只使用 `branches` 现有字段。
- 不做拖拽建树；新建与移动走侧栏表单。

## 3. 用户故事与主流程

**故事 1｜从零建一条一级分支**

`/branches` 空态 → 点「新建分支」→ 右侧栏填写名称、选择「根下」、选一个预设色相 → 保存 → 树中出现该一级分支，默认追加到同层末尾，额度显示从 0/7 变 1/7。

**故事 2｜在分支下加一个具体目标**

分支行尾「更多」→「新建子分支」→ 父分支已预填、色相继承 → 填名称 → 保存 → 子分支在该父下展开显示；到三层后「新建子分支」不可用并写明原因。

**故事 3｜改名**

行尾「更多」→「重命名」→ 输入新名称 → 边输入边显示同级重名/状态校验 → 保存 → 树与路径同步，历史不变。

**故事 4｜把一条分支挪到另一条线下**

行尾「更多」→「移动」→ 选择目标父分支 → 面板显示目标路径与各候选剩余名额，不可选的原因逐条写出 → 确认 → 整棵子树随父移动，深度与额度重新校验。

**故事 5｜看某条分支的详情**

点分支名称进入 `/branches/:id`（M04）；点展开控件只改变展开状态，不跳转；点行尾「更多」打开贴着该行的菜单。

**异常与边界**

- 同级已有同名（含已归档的同级）→ 拒绝并保留输入，指明冲突名称。
- 目标父分支是自身或后代 → 不可选，写明「不能移动到自身或自己的子分支下」。
- 移动后子树深度超过 3 层 → 不可选，写明「移动后会有第 4 层」。
- 目标父分支已达该层上限（7 / 9 / 20）或全树已达 200 → 不可选，显示剩余名额 0。
- 根分支：不显示删除、移动、收尾、放下；可改名与改色。
- 已合并但留在默认树的分支：结构只读，菜单只显示可执行动作，其余标灰并说明原因。
- 写入失败：保留表单输入与已选目标，提示失败原因并提供重试；树不出现半成品节点。

## 4. 界面与交互

对应页面：**P02**（`/branches`）。视图：**B01–B05**。

### 4.1 树（D-01）

- 单根「我」，层级为根 → L1 → L2 → L3；不能出现第 4 层。
- 按一级分支分组；默认展开 L1 与 L2，L3 折叠；展开状态在返回页面后恢复。
- 每行显示：分支名、状态、进度（本分支自己的 `taskDone/taskTotal`）、行尾「更多」。
- 点名称进入详情；点展开控件只切换该行子树；点「更多」打开锚定菜单，不改变选中态。
- 页脚显示全树额度使用情况（如「已使用 12 / 200 条分支」）。
- 窄屏保留层级缩进、状态、展开控件与行尾操作；次要统计进入详情，不在行内挤压。

### 4.2 新建与编辑（B02–B05）

| 视图 | 字段 | 校验与反馈 |
| --- | --- | --- |
| B02 新建一级分支 | 名称、父位置固定为根、预设色相 | 名称非空、同级唯一、L1 ≤7、全树 ≤200；面板显示「已使用 3 / 7 个名额」 |
| B03 新建子分支 | 名称、父分支（预填当前行）、色相（继承） | 层级 ≤3；父下 L2 ≤9、L3 ≤20；同级重名；全树 ≤200 |
| B04 重命名 | 名称 | 保留输入，即时显示重名与状态校验 |
| B05 移动 | 目标父分支 | 展示新父分支与新路径；逐条解释层级、循环引用、额度、状态、重名导致的不可选 |

- 新建成功：新分支追加到同层末尾，树自动展开到可见位置，焦点落到新行。
- 改名成功：树、面包屑、详情页头同步；`path` 不变。
- 移动成功：整棵子树的 `path` 前缀替换、`depth` 重算；页面停留在原分支详情时刷新为新路径。
- 所有失败都留在原面板，不清空输入，不关闭面板。

### 4.3 行尾菜单（B01）

- 菜单贴着分支行出现，不居中悬浮。
- 按阶段与状态显示动作：新建子分支、重命名、移动、收尾（M08）、删除（M08）；V1 起追加放下、归档、取消归档、重新开始（V1-01）。
- 不可用项保留在菜单中，置灰并给出原因；不隐藏整项，避免用户以为功能不存在。
- 打开后焦点进入菜单，`Esc` 关闭并返回触发按钮；点击外部关闭。

### 4.4 五种状态

| 状态 | 表现 |
| --- | --- |
| 空 | 只有根分支「我」；给一句「还没有分支，待办可以直接记在『我』上」+「新建分支」；不强制先建分支 |
| 加载 | 保留树的基本行高与缩进，不整屏 spinner；加载完成后不跳动 |
| 错误 | 树读取失败：保留外框，说明原因 + 重试；写入失败：保留表单与目标 |
| 只读 | 已合并但仍留在默认树的分支行只读；菜单中的结构动作置灰并写明原因 |
| 无权限或未登录 | 不适用；MVP 无账号，分支页不得要求登录 |

### 4.5 移动端

- 390 px：树占满主列，保留缩进与行尾「更多」；长名称单行省略，进入详情看全名。
- 侧栏改为全屏面板，顶部有标题与关闭；键盘弹出时保存按钮保持可见。

## 5. 数据与规则

| 表 | 字段 | 用途 |
| --- | --- | --- |
| `branches` | `_id`、`parentId`、`path`、`depth`、`title`、`goal`、`color`、`status`、`order`、`pinnedAt`、`archivedAt`、`taskTotal`、`taskDone`、`commitCount`、`ownLastCommitAt`、`createdAt`、`updatedAt`、`deletedAt` | 树渲染、校验、额度、路径 |
| `events` | `entityType='branch'`、`action='branch.create'` / `'branch.rename'` / `'branch.move'`、`payload`、`at` | 新建、改名、移动留痕（删除空分支除外，见 R13）；移动整棵子树只写一条，`payload.movedCount` 记受影响节点数 |

规则：

- R16 额度：根 1 个；L1 ≤7、L2 ≤9、L3 ≤20 个直接子分支；全树 L1–L3 ≤200。只算未归档、未删除的分支；已合并或已放下但仍在默认树的分支照常计入；自身与后代不可作为移动目标。
- 同级重名：同一 `parentId` 下名称唯一，**包含已归档的同级分支**。
- 层级：`depth` 0–3；新建时父 `depth + 1 ≤ 3`；移动后整棵子树最大 `depth ≤ 3`。
- 路径：`path` 为 `_id` 拼接；改名不改 `path`；移动按前缀替换；查询子树用 `path` 前缀。
- K-03 颜色：`color` 只取 7 个预设（`coral` / `sky` / `honey` / `mint` / `iris` / `rose` / `teal`）；子分支默认继承父色相，L2、L3 用同色相更浅一档；颜色在树、详情、历程、年轮、分享图必须一致；不提供自由取色。
- 根分支：首次进入工作区时自动存在，标题「我」，不可删除、不可合并、不可放下；根不计入 200，也不计入「新开」统计。
- 四个计数只统计本分支、不含后代（R7）；本 PRD 只读取展示，写入由 M03/M05/M08 维护。
- 软删：普通分支删除走 `deletedAt`（M08 的空分支物理删除是唯一例外，见 R13）。

## 6. 验收标准

1. 空树只有根分支「我」；不建分支也能在根上记待办（跳转 M03 验证）。
2. 连续新建 7 条一级分支成功；第 8 条被拒绝，显示「已使用 7 / 7 个名额」或等价原因，输入保留。
3. 在 L1 下建 L2、L3 成功；在 L3 下点「新建子分支」不可用，并写明「最多 3 层」。
4. 同一父下创建同名分支被拒绝，输入保留；把同名分支归档后再建，仍被拒绝。
5. 重命名时输入已存在的同级名称，保存不可用并即时提示；改名成功后树与详情页头同步，`path` 不变。
6. 把父分支移动到自己的子分支下不可选，原因写明；移动到自身不可选。
7. 把一棵含两层的子树移到 L2 下，若会产生第 4 层则不可选并写明原因。
8. 移动到已满 7 / 9 / 20 的父下不可选，显示剩余 0；移动到未满父下成功，树位置与新路径正确。
9. 子分支创建后默认继承父色相；在任意视图看到的分支颜色与树一致；界面无自由取色入口。
10. 点分支名称进入 `/branches/:id`；点展开控件不跳转；点「更多」菜单贴着该行出现，`Esc` 关闭后焦点回到「更多」。
11. 刷新页面后树的展开状态、当前选中导航与滚动位置恢复。
12. 390 px 下树保留缩进、状态、展开与行尾操作，侧栏表单为全屏面板且可关闭。

## 7. 依赖与阶段、未决问题

- 阶段：MVP。
- 依赖：M01（外框、空态、偏好、本地存储）。
- 后续消费：M03 今天与待办、M04 分支详情、M08 收尾、M06 历程泳道、M11 徽章（第一道岔）、M12 引导。
- 未决问题：
  - 父分支达上限时，除删除空分支外是否允许直接归档释放额度：MVP 只有收尾时归档（M08），V1 才有手动归档（V1-01）；提示文案需与阶段一致。

### 本份实现决定（自主决断记录）

- **移动不受「全树 200」阻断**：移动不改变全树分支数量，OP-05 中「全树满 200 时不可选」按新建口径理解；移动只校验目标父下直接子名额（7 / 9 / 20）、层级、循环引用、目标状态与重名。
- **改色范围**：本份只在新建一级分支时选择预设色相，子分支继承父色相；§8.1 未列「修改已有分支颜色」的操作，B04 字段也只有名称，因此改名面板不提供改色入口，根分支「可改名与改色」中的改色留待后续有明确视图时补。
- **已合并 / 已归档分支**：菜单保留新建子分支、重命名、移动并全部置灰，原因写「已合并或已归档，结构只读」；收尾与删除空分支以「后续版本提供」占位，避免用户以为功能不存在。
- **移动候选列表**：保留当前父分支与已归档目标，逐项置灰并写明原因（已在该父下 / 结构只读 / 自身或后代 / 第 4 层 / 名额已满 / 重名），可用项显示剩余名额。
- **根分支创建时机**：工作区存储就绪后由应用外壳调用 `ensureRootBranch()`；用例幂等，StrictMode 重复执行安全。
- **读失败兜底**：分支页使用 `useBranchesView` 把读取异常收成页面内错误态（保留外框 + 重试），不让 `useLiveQuery` 的异常打到整页错误边界。
- **展开状态持久化**：`branches.store` 只存覆盖值，默认 L1 / L2 展开、L3 折叠，经 Zustand `persist` 存入 `localStorage` 的 `branches.expanded`。
- **新建后的定位**：保存成功按返回分支的 `path` 展开全部祖先，再把焦点落到新行并滚动到可见区域；改名 / 移动同样把焦点放回该行。

最值钱的回归用例：`branch-path.test.ts` 的「`/work` 与 `/workshop` 前缀相近」——守的是用字符串 `startsWith` 做子树查询、把同前缀的兄弟分支一起改掉的 bug；手工验收的树通常只有几条短名分支，不会碰巧造出同前缀兄弟。`branch-quota.test.ts` 与 `branch-name.test.ts` 的「已归档分支」组合——守的是把额度与重名共用同一份「忽略已归档」过滤器的 bug：额度必须排除已归档，重名必须包含已归档，手工验收要同时准备「满额父」和「已归档同级」才看得出差异。

### 8.3 只能人工验收

1. **三层树与窄屏缩进**：预置 3 层分支与一条超长名称；判定为缩进表达层级、长名单行省略、进入详情可看全名、390 px 下行尾「更多」可见且不依赖悬停；1440 与 390。为什么不能进单测：溢出省略与缩进属于布局。
2. **新建后的焦点与自动展开**：在折叠的 L1 下新建子分支；判定为树自动展开到新行、焦点落在新行、滚动使新行可见；1440 与 390。为什么不能进单测：焦点流转与滚动定位依赖真实 DOM 与浏览器行为。
3. **行尾菜单定位与 Esc**：打开任一分支的「更多」；判定为菜单贴着该行、不居中悬浮、`Esc` 关闭后焦点回到「更多」、点击外部关闭；1440 与 390。为什么不能进单测：锚定定位与焦点返回无法在 `jsdom` 判定。
4. **刷新恢复展开与选中**：展开若干层并滚动后刷新；判定为展开状态、当前选中导航与滚动位置三者复原；1440。为什么不能进单测：依赖浏览器历史与滚动容器。
5. **写入失败保留表单**：制造 IndexedDB 写入失败后保存新分支；判定为面板不关闭、输入与已选父保留、提示可重试、树上无半成品节点；1440。为什么不能进单测：需要真实写入失败。
6. **加载骨架不跳动**：预置 50 条分支并节流资源；判定为骨架期不出现整屏 spinner、加载完成后行高与缩进不跳；1440。为什么不能进单测：测的是时序中的布局稳定性。
7. **窄屏面板与键盘**：390 px 打开 B03；判定为全屏面板、键盘弹起时保存按钮仍可见、关闭入口可见；390。为什么不能进单测：移动端键盘行为只有真实设备或视口能复现。
