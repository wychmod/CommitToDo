# V1-03 回顾扩展与分享图（V1）

## 1. 背景与目标

MVP 的周回顾只在周末出现，回答「这一周发生了什么」。V1 要把它变成长期可用的回看工具：周中也能看到本周到今天的摘要；周日晚上提醒一次；每月换一个维度看结构变化；把一年的历程生成一张可以自己留存的分享图。

本 PRD 交付 C-03 本周摘要、G-02 回顾提醒、G-03 月回顾、G-04 年度分享图，以及 S01-month-review、S05-year-share 两个视图。周分享图因缺视觉稿，本期不实现，处理方式见 §7。

目标：用户在工作日打开今天页能一眼看到本周进度；在月初能看到上个月的重心与结构变化；在年轮页生成一张 4:5 的年度分享图并保存到本机。

## 2. 范围与非目标

**范围**

- C-03 本周摘要：在 G-01 同一张卡片上增加「本周摘要」，每天显示当前周（周一至周日）截至当天的有效提交数与停滞分支提示。
- G-02 回顾提醒：周日 20:00 后，在今天页提示一次查看本周回顾；可关闭。
- G-03 月回顾：从回顾区打开，按月展示结构变化，不重复周报的活动视角。
- G-04 年度分享图（S05）：年轮页生成 4:5 预览，主体为泳道缩略，数字放角落；默认隐藏待办标题，分支名可选显示。
- 回顾区的入口扩展与 S01-month-review 面板。

**非目标**

- **周分享图本期不做**：缺 4:5 周分享图视觉稿，本期不设计入口、不生成周图；周回顾的数据与文字不受影响（详见 §7）。
- 不做分享到社交平台、不做上传服务端、不做二维码与链接分享。
- 不做补看往周、不做往月回顾的编辑、不做回顾内容的输入与心情记录。
- 不做系统推送或浏览器通知权限申请；提醒只在应用内出现。
- 不改表结构；本周摘要、月回顾、分享图全部现算。

## 3. 用户故事与主流程

**故事 1｜周三看到本周进度**

周三打开 `/today` → 回顾卡出现折叠态「本周摘要 · 本周 6 次提交 · 1 条分支停滞」→ 点开只显示本周摘要，不出现周回顾正式版与提问。

**故事 2｜周日晚上被提醒一次**

周日 20:10 打开今天页 → 页面顶部出现一条轻提示「本周回顾可以看了」+「查看」+「今天不再提示」→ 点「查看」展开周回顾；点关闭后本次会话不再出现；在设置里关闭提醒后，任何时间都不再出现。

**故事 3｜月初看 10 月的结构**

今天页回顾区点「月回顾」→ 默认上月 → 面板显示提交数、一级分支比重及与前一月的对比、新开 / 收尾 / 放下、停滞分支、一句数据观察 → 切换月份查看更早的月份。

**故事 4｜生成年度分享图**

`/history/2026` 点「分享」→ 打开 4:5 预览：主体是泳道缩略，角落是「2026 · 128 次提交」等数字 → 分支名开关默认关闭 → 打开后预览中的分支名出现 → 点「保存图片」→ 图片保存到本机。

**异常与边界**

- 本周无提交：本周摘要显示 0 次提交与停滞提示，不隐藏卡片；周回顾正式版仍按 M09 的「无提交不出现」处理。
- 当天是周一：本周摘要显示本周（新一周）截至当天；周回顾展示上一周正式版（M09）。
- 周日 23:59 打开、周一 00:01 仍停留：提醒不重复出现；周回顾按 M09 消失。
- 提醒已关闭：不出现任何提示；再次打开不补发历史提醒。
- 月回顾所选月份没有提交：仍打开面板，提交数为 0，结构变化照常显示，给一句「这个月没有留下提交」。
- 月回顾跨越时区：月份边界按本机当前时区的自然月；历史提交按写入时的业务日期归属月份。
- 分享图为空年：没有有效提交时「分享」不可用并写明原因；只有里程碑的年份同样不可用。
- 分享图生成失败：保留预览与开关，提示重试；不下载半张图。
- 分支名为空或包含换行：分享图不渲染该分支名，不报错。
- 关闭本周摘要：只影响本次会话的展开状态，不写设置。

## 4. 界面与交互

对应视图：**S01-week-review**（扩展）、**S01-month-review**、**S05-year-share**；入口在 P01 今天页回顾区与 P05 年轮页。

### 4.1 本周摘要（C-03）

- 挂在 M09 的同一张回顾卡上，不新增卡片。
- 每天出现；折叠态一行包含：本周截至今天的有效提交数、停滞分支数。
- 展开后：
  - 本周提交：本周一 00:00 至当前时刻的有效提交数（R3）。
  - 停滞分支：按 R4 判定、当前在默认树可见的停滞分支数；大于 0 时列出一句「X 条分支超过 30 天没有提交」，最多列 3 个分支名。
- 周二至周五：展开面板只显示本周摘要，不显示周回顾的正式版、提问与环比。
- 周六、周日、周一：本周摘要与 M09 的周回顾同时出现，本周摘要在上，周回顾在下；两者的日期区间分别标注。
- 本周摘要只读，不可输入。

### 4.2 回顾提醒（G-02）

- 触发条件：本机时区周日 20:00 之后、当天结束之前，用户进入今天页。
- 形态：今天页顶部一条可关闭的轻提示，文案「本周回顾可以看了」+「查看」；「查看」展开周回顾面板并关闭提示。
- 每次进入应用最多出现一次；关闭后本次会话不再出现；刷新页面视为新会话，但在同一自然日内再次出现不超过一次。
- 开关：设置页「回顾提醒」默认开启，关闭后周日不再出现任何提示（`settings.reminderEnabled`）。
- 不使用系统通知、不申请通知权限；应用未打开时不提醒。

### 4.3 月回顾（S01-month-review）

- 入口：今天页回顾区的「月回顾」；默认上月，可切换到有数据的更早月份。
- 面板固定五个区块：

| 区块 | 内容 | 口径 |
| --- | --- | --- |
| 总量 | 该月有效提交数 | R3；按 `date` 归月 |
| 比重 | 一级分支占比，及与前一月的差值 | 子分支提交归一级祖先；差值按百分点 |
| 结构 | 新开、收尾、放下 | `createdAt` / `finishedAt` 且 `status=merged` / `droppedAt` 落在该月 |
| 持续 | 截至该月最后一天的停滞分支数与最长停滞天数 | R4；以该月最后一天为「今天」计算 |
| 观察 | 一句由数据生成的描述 | 只陈述事实，不评价、不建议、不可输入 |

- 比重变化只在差值绝对值 ≥10 个百分点时标出「上升 / 下降」，否则不强调。
- 观察句按固定模板从以下事实中选一条：集中度（Top1 占比 ≥50% 为集中，≤30% 为均匀）、连续出现（某一级分支在该月 ≥3 个自然周有提交）、结构变化（该月新开或收尾数量最多的一项）。
- 面板只读，不提供任何输入；不做「放大版周报」，不重复周回顾的提问。

### 4.4 年度分享图（S05）

- 入口：P05 年轮页「分享」；该年有效提交数为 0 时入口置灰并写明原因。
- 预览：4:5 画幅，主体为泳道缩略（按一级分支分条，节点为提交，汇合点可省略），角落放年份与该年四项指标中的关键数字。
- 隐私：待办标题始终不出现；分支名默认隐藏，开关打开后才渲染。
- 开关状态只属于本次预览，不持久化；关闭预览后重置为隐藏。
- 保存：点「保存图片」生成一张 4:5 图片并保存到本机；文件名包含年份。
- 分享行为由用户自行完成；产品不上传、不生成链接、不统计分享次数。

### 4.5 五种状态

| 状态 | 表现 |
| --- | --- |
| 空 | 本周无提交：摘要显示 0 与停滞提示；月回顾无提交：显示 0 与结构变化；分享图无提交：入口不可用并说明 |
| 加载 | 回顾卡与月回顾保留标题和区块骨架，不整屏 spinner；分享预览显示画幅占位 |
| 错误 | 统计读取失败：卡片保留标题，面板说明 + 重试；分享生成失败：保留预览与开关并提示重试 |
| 只读 | 本周摘要、月回顾、分享预览全部只读；分享图只有「分支名显示」一个开关 |
| 无权限或未登录 | 不适用；V1 无账号，回顾与分享不要求登录 |

### 4.6 移动端

- 390 px：回顾卡位于今天清单之后，提醒条位于页面顶部且不遮挡底部导航。
- 月回顾为全屏面板，区块纵向排列，可返回今天页。
- 分享预览为全屏，4:5 画幅等比缩放，保存按钮固定在底部；分支名开关可点击。

## 5. 数据与规则

| 表 | 字段 | 用途 |
| --- | --- | --- |
| `commits` | `date`、`at`、`branchId`、`sourceBranchId`、`voidedAt` | 本周、本月、该年的提交数与分支占比 |
| `branches` | `_id`、`parentId`、`path`、`depth`、`title`、`color`、`status`、`archivedAt`、`createdAt`、`finishedAt`、`droppedAt`、`ownLastCommitAt`、`deletedAt` | 结构变化、停滞、泳道与颜色 |
| `settings` | `reminderEnabled` | 回顾提醒开关 |
| 页面上下文 | 本机时区与当前日期 | 周、月、年的边界与提醒时点 |

规则：

- R3 有效提交：本周摘要、月回顾、分享图只统计 `voidedAt == null` 的提交。
- R4 停滞：只判断进行中、未归档、默认树可见的分支；天数 = 今天 − `ownLastCommitAt`；月回顾以该月最后一天为今天计算。
- R9 周回顾：M09 的出现规则与统计口径不变；本周摘要不改变周回顾的日期窗口。
- R10 月回顾：精力分布按一级分支的有效提交占比；结构变化读 `createdAt`、`finishedAt`、`droppedAt`；停滞按该月最后一天计算。
- R11 年轮：分享图复用年轮的四项指标、一级分支占比与泳道数据，不另算一套。
- 一级祖先归属：沿 `parentId` 上溯到 `depth = 1`；根分支上的提交归入「我」，在分享图中单独一条泳道。
- 周、月、年边界均按本机当前时区的自然周期；历史提交按写入时的业务日期 `date` 归属。
- 提醒只在应用内出现，不写 `events`、不触发系统通知。
- 本月摘要与月回顾都不落库，不新增 `counters`。

## 6. 验收标准

1. 周三打开 `/today`，回顾卡显示本周截至当天的提交数与停滞分支提示；展开后不出现周回顾正式版与提问。
2. 周六打开 `/today`，本周摘要与周回顾同时出现，日期区间分别标注；周一打开时周回顾为上一周正式版，摘要为新一周。
3. 本周无提交时，摘要显示 0 次提交；停滞分支数为 0 时显示「没有停滞的分支」，不隐藏卡片。
4. 周日 20:00 后进入今天页，提醒出现一次；点「查看」展开周回顾并关闭提醒；同一自然日内刷新后最多再出现一次。
5. 在设置关闭「回顾提醒」后，周日 20:00 后进入今天页不出现任何提示；应用未打开时不产生提醒。
6. 打开月回顾默认上月；切换月份后五个区块全部按该月重算，提交数与直接统计 `commits` 的结果一致。
7. 某月一级分支占比变化 12 个百分点时标出上升或下降；变化 5 个百分点时不强调。
8. 某月新建 2 条、收尾 1 条、放下 1 条：结构区块显示 2 / 1 / 1；放下不计入收尾。
9. 月回顾的停滞分支数与最长停滞天数以该月最后一天计算；今天新增提交不改变历史月份的结果。
10. 月回顾只出现一句数据观察，没有输入框、选项、建议或评价文案。
11. 年轮页点「分享」打开 4:5 预览；泳道缩略与数字可见，待办标题不出现；分支名默认隐藏，打开开关后出现，关闭预览后重置。
12. 点「保存图片」得到一张 4:5 图片并保存成功；该年有效提交为 0 时「分享」不可用并写明原因。
13. 撤销该年一条提交后重新生成分享图，数字与泳道同步减少。
14. 人为使分享生成失败：预览与开关保留并提示重试，不产生下载文件。
15. 390 px 下月回顾为可返回的全屏面板，分享预览等比缩放且保存按钮可见。

## 7. 依赖与阶段、未决问题

- 阶段：V1。
- 依赖：M09（周回顾卡片与统计口径）、V1-02（年轮四项指标与泳道数据）、M06（泳道与颜色）、M08（收尾时间）、V1-01（放下时间）。
- 后续消费：V1-05 的「常青」「第一年」等徽章与回顾共用提交口径，但不读取回顾结果。
- 冲突与处理：
  - `FRAMEWORK` C-03 是 V1 项，`UI-PAGES` 未单列视图：按同一张回顾卡扩展，不新增页面或视图编号。
  - `FRAMEWORK` G-04 写「周 / 年两种」分享图，`UI-PAGES` 只有年度分享图 S05，且缺周分享图视觉稿：**本期只交付年度分享图**，周分享图记为视觉待办。缺什么：4:5 周分享图的版式、泳道缩略、数字位置、明暗两套。卡住什么：G-04 的「周分享图」一条无法进入实现与验收，本周回顾卡不出现分享入口。不阻塞什么：周回顾的数据、文字与提问（R9）、本周摘要、月回顾、年度分享图、徽章。视觉补齐后按同一 S05 能力增量实现，不改变本期结构。
  - `FRAMEWORK` G-02 写「周日 20:00 提示」，纯本地应用没有系统推送：实现为「周日 20:00 后首次进入今天页时应用内提示一次」，不做通知权限申请；开关复用 `settings.reminderEnabled`。
  - `PAGE-DATA-CROSSCHECK` D14 提到分支名显示选择可能需要持久化：本期定为仅本次预览有效，不落库。
- 未决问题：
  - 分享图的保存方式（直接下载文件或打开系统分享面板）取决于浏览器与平台能力，本期按「保存到本机」验收，不绑定具体 API。
  - 月回顾「持续」区块的最长停滞天数是否需要展示具体分支名，取决于面板高度，当前只显示条数与最长天数。
  - 提醒在周日 20:00 前已打开应用、20:00 后不刷新时是否补提示，当前按「不补、下次进入再判断」处理。
