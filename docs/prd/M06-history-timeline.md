# M06 历程时间树（MVP）

## 1. 背景与目标

历程是产品的「看见层」：把散落的完成记录放回分支结构里，让人一眼看到哪条线在动、哪条线停了、什么时候分叉、什么时候合回。今天页回答「现在做什么」，历程回答「我这一年走成了什么样」。

目标：打开 `/history`，默认看到近 90 天、按一级分支分泳道的时间树；能展开子分支、看停滞虚线、切换时间范围与分支筛选，并从节点直达提交或里程碑。

## 2. 范围与非目标

**范围**

- F-01 时间树：每条一级分支一条泳道；子分支在创建处分叉、收尾处合回；按时间比例排布；邻近节点聚合；默认展开未归档 L1、折叠子分支与已归档 L1；默认近 90 天，滚动加载更早区间。
- F-02 停滞虚线：进行中分支超过 30 天无有效提交画虚线到今天并标天数；范围内无提交但历史有提交画淡实线；从未有有效提交不计；已放下画灰线并标放下日期。
- F-03 筛选与直达：一个时间范围控件（近 90 天 / 今年 / 全部）；按根分支或一级分支筛选；记住上次范围与筛选；从首条提交、徽章、搜索直达目标泳道与日期并高亮，保留原筛选设置。
- P04 历程页；提交节点、里程碑节点、分叉点、合并点的详情入口。
- 今天页「停滞提醒」区块（最多 5 条）。

**非目标**

- 不做年轮（V1-02）；不做分享图（V1-03）；不做全局搜索（V1-04）；不做徽章墙（V1-05）。
- 不做节点拖拽、手工调整时间轴、导出图片。
- 不新增表或字段；不把「停滞」做成状态。

## 3. 用户故事与主流程

**故事 1｜看这三个月哪条线在动**

打开 `/history` → 默认近 90 天 → 每条一级分支一条泳道，未归档 L1 展开、子分支折叠 → 有提交的位置出现节点，节点密度按真实时间比例排布 → 长时间没有提交的分支出现虚线到今天，并标注天数。

**故事 2｜展开一条子分支看细节**

点 L1 泳道上的展开控件 → 子分支从父线分叉处展开，分叉点位于子分支创建日 → 子分支的提交出现在自己的线上 → 收尾时在合并点收束回父线，合并点可点开查看去向与日期。

**故事 3｜只看「工作」这条线**

时间范围选「今年」→ 分支筛选选「工作」→ 其他泳道隐藏，只保留「工作」及其子分支 → 刷新或离开再回来，仍是「今年 + 工作」。

**故事 4｜从徽章直达第一段路**

在「我的」点徽章跳到历程 → 页面定位到第一条提交所在泳道与日期并高亮 → 当前筛选与时间范围不被这次跳转改写。

**故事 5｜看今天页的停滞提醒**

今天页侧栏出现「这些线停了一阵」→ 最多 5 条，按停滞天数从多到少 → 点一条进入对应分支或历程位置。

**异常与边界**

- 时间范围切换后目标区间无节点：显示该区间的空态，不自动扩大范围。
- 邻近节点过密：聚合为一个带数量的节点；点开后列出该簇内节点，选中进入详情。
- 分支在区间开始前已创建、区间结束后才收尾：分叉点落在区间左侧边界外时以边界截断显示，不虚构日期。
- 分支已归档：默认折叠，展开后只读查看历史；不画停滞虚线。
- 分支已放下：画灰线到放下日期并标注「已放下」，不画虚线到今天。
- 从直达进入后用户修改筛选：以用户新选择为准，并更新记住的筛选。
- 数据读取失败：保留页头与筛选控件，图表区说明 + 重试，不清空已加载区间。
- 今天页停滞提醒为空：不显示该区块，不占位。

## 4. 界面与交互

对应页面：**P04**（`/history`）。

### 4.1 泳道与节点（F-01）

| 元素 | 规则 |
| --- | --- |
| 泳道 | 每条一级分支一条；根分支有提交、里程碑或合并时额外显示根泳道 |
| 分叉 | 子分支在 `createdAt` 对应位置从父线分出 |
| 合回 | 收尾后在 `finishedAt` 对应位置合回父线；合并点标注去向与日期 |
| 节点 | 提交节点按 `date` 与时刻定位；里程碑按 `achievedAt` 与 `datePrecision` 定位 |
| 邻近聚合 | 距离过近的节点聚合为数量节点；点开后列出簇内节点 |
| 展开 | 默认展开未归档 L1；子分支与已归档 L1 默认折叠；展开状态在本次会话内保留 |
| 时间轴 | 按真实时间比例；范围切换后重新计算刻度 |
| 加载 | 默认近 90 天；滚动或拖动到边界时加载相邻更早区间 |

- 点击提交节点进入 O03 提交详情（M05）；点击里程碑节点进入 S04（M07）；点击分叉/合并点显示该分支的创建或收尾信息与去向。
- 节点只显示日期与文案摘要；不显示短 hash（R5）。

### 4.2 停滞虚线（F-02 / R4）

- 只对 `status=active` 且未归档的分支计算。
- 最近有效提交取「本分支 + 未归档且未放下的后代」中 `at` 最大的那条（R3，忽略已撤销）。
- 「可见后代」= 未归档且未放下的后代，与当前是否展开无关；它直接决定虚线长度与测试边界。
- 超过 30 天：从最后一条有效提交日期画虚线到今天，并在末端标注天数。
- 当前可见范围内没有有效提交、但历史上存在有效提交：画淡实线，不标天数。
- 从未有过有效提交：不计停滞、不画虚线（R4）。
- 已放下：灰线到 `droppedAt`，标「已放下」，不画到今天。
- 已归档：不参与停滞，仅展示历史。
- 今天页停滞提醒：取停滞分支中天数最多的 5 条，按天数降序；无则不显示。

### 4.3 筛选与直达（F-03）

- 一个时间范围控件，三档：近 90 天（默认）/ 今年 / 全部；「今年」从 1 月 1 日或近 90 天中更早者开始。
- 分支筛选：根分支或任一 L1；选中后只显示该线及其子分支，其他泳道隐藏。
- 记住：时间范围与分支筛选写入本机 UI 状态；正常进入使用上次设置。
- 直达：从首条提交回执、徽章、搜索结果进入时，定位到目标泳道与日期并高亮；这次跳转不改写已记住的筛选与范围；离开后下次正常进入仍用原设置。
- 直达目标被当前筛选隐藏时，临时显示目标泳道并在顶部提示「已临时显示目标分支」，不修改保存的筛选。

### 4.4 五种状态

| 状态 | 表现 |
| --- | --- |
| 空 | 从未有提交：「完成第一条待办后，这里会出现你的第一段路」+ 去今天；筛选后为空：说明当前范围无节点 + 清除筛选 |
| 加载 | 保留页头、筛选与刻度；泳道骨架按行高占位；加载后不整体跳动 |
| 错误 | 图表区说明原因 + 重试；已加载区间保留；筛选控件可用 |
| 只读 | 已归档分支展开后只读；节点可查看，不提供任何写入 |
| 无权限或未登录 | 不适用；MVP 无账号 |

### 4.5 移动端

- 390 px：横向时间树改为纵向时间线，保留分支名、日期、分叉/合回、停滞标注与节点点击。
- 时间范围与分支筛选收进一个可展开的筛选条；切换后不回到页面顶部。
- 节点详情为全屏面板，保留关闭入口。

## 5. 数据与规则

| 表 | 字段 | 用途 |
| --- | --- | --- |
| `commits` | `branchId`、`sourceBranchId`、`date`、`at`、`summary`、`voidedAt` | 提交节点、来源、停滞最近日期 |
| `branches` | `parentId`、`path`、`depth`、`status`、`createdAt`、`finishedAt`、`finishedIntoId`、`droppedAt`、`archivedAt`、`ownLastCommitAt` | 泳道、分叉、合回、灰线、停滞 |
| `milestones` | `branchId`、`achievedAt`、`datePrecision`、`title` | 里程碑节点 |
| 本机 UI 状态 | 时间范围、分支筛选、展开状态 | 记住上次设置，不进业务库 |

规则：

- R3 有效提交：节点、最近提交、停滞只看 `voidedAt == null`。
- R4 停滞：仅 `active` 且未归档；取自己与未归档且未放下的后代中最近有效提交（与展开状态无关）；>30 天才画虚线；从未有有效提交不计；已放下不画到今天。
- R6 里程碑日期：`day` 显示具体日，`month` 对齐到月份列，不补虚构的日。
- 合并口径：提交并入父分支后 `branchId` 为父、`sourceBranchId` 保留原分支；泳道归属按 `branchId`，来源标注按 `sourceBranchId`。里程碑不迁移 `branchId`，已并入子分支的里程碑仍在父泳道显示并标注来源（按 `finishedIntoId` 关系纳入）。
- 时间范围：以本地自然日计算；「近 90 天」含今天往前 90 个自然日；「今年」从 1 月 1 日或近 90 天更早者开始。
- 聚合只影响渲染，不改变节点顺序与详情内容。
- 直达不改写保存的筛选；只有用户手动修改筛选时才覆盖。

## 6. 验收标准

1. 打开 `/history` 默认近 90 天，每条未归档 L1 一条泳道并展开，子分支与已归档 L1 默认折叠。
2. 在 L1 下新建子分支并完成一条待办，子分支线在创建日从父线分出，提交节点落在子分支上；收尾后在该日合回父线并标注去向。
3. 根分支有提交或里程碑时出现根泳道；根无活动时不出现。
4. 提交节点按真实时间比例排布；同一周内节点过密时聚合为数量节点，点开可看到簇内条目并进入详情。
5. 一条进行中分支超过 30 天无有效提交，虚线画到今天并显示天数；30 天内不画虚线。
6. 一条分支历史上提交过但当前范围无提交，显示淡实线且不标天数；从未提交过的分支不画虚线、不计停滞。
7. 已放下分支显示灰线到放下日期并标「已放下」，不画到今天；已归档分支不参与停滞。
8. 时间范围切到「今年」「全部」后刻度与节点重算；切回「近 90 天」结果一致。
9. 选择分支「工作」后仅显示该线及其子分支；刷新后仍保持「今年 + 工作」。
10. 从徽章或首条提交回执直达，定位到目标泳道与日期并高亮；离开再正常进入，仍使用原先保存的筛选。
11. 今天页停滞提醒最多 5 条，按天数降序；无停滞分支时区块不出现。
12. 390 px 下改为纵向时间线，保留分叉、合回、停滞标注与节点点击。
13. 图表读取失败时保留筛选与已加载区间，提供重试；不出现整页空白。

## 7. 依赖与阶段、未决问题

- 阶段：MVP。
- 依赖：M03（提交生成）、M05（提交详情）、M02（分支创建与收尾时间）。
- 后续消费：M07 里程碑节点、M09 周回顾、M11 徽章直达、V1-02 年轮、V1-04 搜索直达。
- 冲突与处理：
  - `FRAMEWORK` F-02 写「该范围内从未有过有效提交时画淡实线」，`TECH-ARCHITECTURE` R4 写「无提交历史的分支不计」。区分处理：范围内无提交但历史有 → 淡实线；从未有有效提交 → 不计。
  - 「停滞」不是分支状态，不能用「暂停」描述；本 PRD 只用虚线与天数表达。
- 未决问题：
  - 聚合阈值（像素距离或节点数）未定，需在实现前给出可验证口径。
  - 滚动加载的区间步长（30 天 / 90 天）未定。
  - 根泳道与 L1 泳道的垂直排序规则未定，当前按根在上、L1 按 `order`。

### 8.3 只能人工验收

1. **真实时间比例与刻度**：预置跨 3 个月的提交；判定为节点横坐标随日期间距成比例、切换范围后刻度重算、切回近 90 天结果一致；1440。为什么不能进单测：测的是像素坐标与刻度布局。
2. **邻近聚合与点开**：预置一周内 12 条提交；判定为聚合为一个带数量的节点、点开后列出簇内条目、选中能进入详情；1440 与 390。为什么不能进单测：聚合阈值依赖像素距离（§7 未决），单测只能验分组结果。
3. **滚动加载更早区间**：滚到左边界；判定为加载相邻更早区间、页头与筛选不动、已加载区间不清空；1440。为什么不能进单测：滚动触发与异步加载属于浏览器行为。
4. **展开状态与会话记忆**：展开一条子分支后刷新页面；判定为展开状态在本次会话内保留、页面不回到顶部、筛选不变；1440。为什么不能进单测：依赖会话状态与滚动容器。
5. **窄屏纵向时间线**：390 px 打开 P04；判定为纵向时间线，保留分叉、合回、停滞标注与节点点击，筛选条可展开且切换后不回顶部；390。为什么不能进单测：布局形态与滚动位置只有真实视口能量。
6. **直达高亮与临时提示**：从徽章直达一条被筛选隐藏的分支；判定为定位到目标泳道与日期、高亮出现且不长期驻留、顶部提示「已临时显示目标分支」；1440。为什么不能进单测：动效与滚动定位。
7. **读取失败保留已加载区间**：制造读取失败后滚到边界；判定为图表区说明 + 重试、已加载区间与筛选仍在、无整页空白；1440。为什么不能进单测：需要真实读取失败。
8. **今天页停滞区块空态**：无停滞分支时打开 P01；判定为该区块不出现、下方内容不留空白、不显示「0 条」；1440 与 390。为什么不能进单测：区块消失后的布局留白无法用纯函数表达。
