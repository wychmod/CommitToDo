# M00 营销首页与工作区入口（MVP）

## 1. 背景与目标

第一次来的人需要一个页面理解「CommitToDo 是什么」，并在不注册、不登录的前提下进入本机工作区。首页不是功能页，它只负责三件事：把「完成一件事 → 树上多一个提交点」讲清楚、用可动手的示例证明这件事、把用户送到 `/today`。

目标：访客在首页完成一次示例勾选、看到回执与时间树上的同一节点，并能从页头或页尾进入工作区。

## 2. 范围与非目标

**范围**

- P00 首页 `/` 的七段内容与明暗两套主题。
- 页头「打开工作区」、页尾「打开 CommitToDo」进入 `/today`；首屏「看工作区」在页内定位到示例。
- 首屏 1.4 秒一次播放、暂停/继续/重播、入视播放、减少动效降级。
- 示例勾选、蓝色回执、点线、时间树节点的联动；回执只定位首页示例，不写入真实数据。

**非目标**

- 不做注册、登录、找回；不在首页读取或写入本机业务库。
- 不做首页之外的营销页面、定价页、博客。
- 不改视觉与文案；颜色、字体、间距一律取 `design-tokens.json` 与 `UI-VISUAL.md`。
- 不把首页示例计入统计、徽章、额度、搜索或备份。

## 3. 用户故事与主流程

**故事 1｜第一次来，想知道这是干什么的**

主流程：打开 `/` → 读到「把『事情做完了』变成『看得见的路』」→ 首屏示例自动播放或手动勾选 → 看到回执「已提交 16:42」与时间树高亮节点 → 点「打开工作区」进入 `/today`。

**故事 2｜不想看动画，只想试用**

主流程：打开 `/` → 点「暂停演示」→ 画面停在当前帧，按钮变「继续演示」→ 点示例待办勾选 → 回执出现、点线连到回执 → 点回执或时间树节点查看示例详情 → 点「打开工作区」。

**故事 3｜直接进工作区**

主流程：在页头点「打开工作区」→ 进入 `/today`。若这是首次进入且本机无数据，由 M12 接管首次引导；首页不承担引导。

**异常与边界**

- 演示启动前用户已滚动到时间树：呈现静态完成示例，保留「重播演示」入口。
- 用户手动勾选：立即接管，自动播放停止，不重复播放。
- 用户暂停后离开首屏再返回：保持暂停，不自动续播；自动播放结束后返回：显示完成态与「重播演示」。
- 系统开启减少动效：首屏直接显示完成画面，时间树与柱状图直接呈现完整静态内容；页内定位立即到达。
- 资源加载失败：正文、入口、示例静态图仍可读；不出现空白首屏。

## 4. 界面与交互

对应页面：**P00**（`/`）。七段顺序与内容以 [UI-PAGES §1.1](../UI-PAGES.md) 为准：

| 段 | 内容 | 交互 |
| --- | --- | --- |
| 1 首屏 | 顶栏（无按钮）、eyebrow、双行标题（「今天」着色）、副文案、两个入口、右侧产品窗、右缘注解 | 「看工作区」页内定位；「打开工作区」进 `/today`；示例勾选；暂停/继续/重播 |
| 2 三块内容 | 今天 / 分支 / 历程三张功能卡 | 首次入视图标各播一次；悬停或聚焦只反馈对应图标 |
| 3 分段导航 | 今天 / 分支 / 历程 | 点击或键盘激活后细线滑动并定位；滚动时追踪当前区块 |
| 4 一处放下，沿路找回 | 今日清单卡 + 历程柱状图卡 | 柱状图首次入视逐根生长；清单手动勾选才反馈 |
| 5 沿着分支，找回每一次完成 | 三泳道时间树，含分叉、合回、选中节点 | 展开控件、节点选择、回执直达高亮 |
| 6 生活里，处处能用 | 做作品 / 跑一公里 / 继续阅读三张场景卡 | 首次入视轻扫；悬停只反馈目标卡 |
| 7 今天就开一页 | 全页唯一实心 CTA、页脚 | 进入 `/today` |

**线的规则**：分支线只在单个演示窗内出现，随区块结束收束；区块之间用背景带与标题分隔，不画贯穿整页的线，不跨区块出画重入。移动端按同序单栏堆叠，删除右缘注解与段内双栏，产品窗左右各裁 24 px，分段导航横向可滚，示例图在容器内横向查看。

**五种状态**

| 状态 | 表现 |
| --- | --- |
| 空 | 不适用；首页没有空数据概念 |
| 加载 | 首屏文字、按钮、静态产品窗先可读，动效后到；不出现整页骨架屏 |
| 错误 | 演示脚本失败时保留静态完成画面与全部入口；不弹错误对话框 |
| 只读 | 不适用 |
| 无权限或未登录 | 不适用；首页不得要求登录，登录入口不出现在首页 |

**键盘与无障碍**：暂停/继续、重播、两个入口、分段导航、示例勾选、时间树节点均可聚焦且有可见焦点；弹层（示例节点详情）焦点进入、`Esc` 关闭、关闭后返回触发控件；节点提供名称与日期的可读文本。

**动效**：首屏 0–200 ms 底纹擦出、200–600 ms 静止、600–720 ms 勾选与便签轻摆、720–1,040 ms 点线、990–1,190 ms 回执抬升、1,190–1,400 ms 完成态；其余区块按 [HOMEPAGE-MOTION.md](../HOMEPAGE-MOTION.md) 的时间点执行。首页营销动效不受应用 320 ms 上限约束。

## 5. 数据与规则

- 首页**不访问** `branches` / `tasks` / `commits` / `badges` / `settings`，不产生写入，不触发徽章。
- 示例节点（「工作 / 产品设计 / 完成线框初稿」、11 月 20 日 16:42）为固定演示数据；示例勾选只改变前端演示状态。
- 入口路由固定为 `/today`；首页不携带 `next`，本机工作区已存在时也直接进入 `/today`。
- 示例与真实数据隔离：统计、额度、搜索、备份、徽章均不计入（A-02 的隔离要求同样适用于首页示例）。
- 主题跟随应用当前主题（默认浅色，用户手动切换过深色则深色），不读取 `prefers-color-scheme`（R19）。

## 6. 验收标准

1. 打开 `/`，首屏「今天。」、勾选、便签、点线、回执按 0–1,400 ms 顺序出现一次，正文与「打开工作区」全程可点击。
2. 点击「暂停演示」后画面停止，按钮变「继续演示」；继续后从暂停时点恢复，不倒带、不跳帧。
3. 自动播放结束后按钮变「重播演示」；重播在当前位置重新演示，滚动位置与焦点不跳。
4. 手动勾选示例待办，回执出现且显示任务名、所属分支「工作 / 产品设计」、时间「16:42」；点回执或时间树节点定位到同一示例节点。
5. 反复勾选、撤销、重播后，示例树上仍只有一个对应节点，不产生第二条提交。
6. 使用系统减少动效时，首屏直接呈现完成画面，时间树与柱状图为完整静态内容，所有入口可点击。
7. 390 px 下任务行与回执完整可见，点线缩短，分段导航可横向滚动，页面自然纵向滚动。
8. 明暗两套主题下正文、回执、焦点、主入口均可见；不出现「跟随系统」。
9. 从页头或页尾进入 `/today`；全程不出现登录要求或注册拦截。

## 7. 依赖与阶段、未决问题

- 阶段：MVP。
- 依赖：无。与 M01 共用设计令牌和明暗主题，但不依赖应用数据。
- 未决问题：
  - 首页是否预渲染、首屏 HTML 的 SEO 细节由技术架构 §3 决定，本 PRD 不展开。
  - 示例节点是否与 M12 示例树共用同一份演示数据，当前按「各自独立、互不计入」处理。
