# V1-02 年轮（V1）

## 1. 背景与目标

今天页回答「我现在做什么」，提交与历程回答「我做完过什么」，但它们都停在最近 90 天。年轮回答更长的问题：这一年我走成了什么样——提交集中在哪几条线、什么时候新开、什么时候收尾、哪条线是自己的主干。

本 PRD 交付 P05 年轮页：按年聚合的四项指标、12 个月分布、一级分支占比与 Top 分支、可编辑的年度总结。所有统计由既有表现算，只新增 `year_reviews` 保存用户手写的一句总结。

目标：用户切到任意一年，能在 5 秒内看清该年的提交总量、结构变化与主要分支；写下一句年度总结并刷新后仍在。

## 2. 范围与非目标

**范围**

- F-05 年轮：年份切换、四项指标、12 个月分布、一级分支分布与 Top 分支、年度总结编辑。
- P05（`/history/:year`）页面；从历程 P04 进入，导航继承「历程」。
- `year_reviews` 表每用户每年一行，只存 `note`。

**非目标**

- 不做分享图与分享预览（S05 归 V1-03）；本 PRD 只在页头预留入口位置。
- 不做跨年对比、同比环比、导出年报到图片或 PDF。
- 不做按月下钻到具体提交列表；点击某个月进入历程并按该月筛选由 V1-04 之后的能力承接，本 PRD 只跳到该年历程。
- 不落任何聚合结果；除 `year_reviews.note` 外不新增字段。
- 不改分支、提交、里程碑的既有规则。

## 3. 用户故事与主流程

**故事 1｜看今年的年轮**

历程页点「年轮」→ 进入 `/history/<当前年>` → 页头显示年份与可切换的年份列表；数字带依次显示提交数、活跃一级分支数、新开、收尾；下方是 12 个月柱状分布与一级分支占比；右侧或下方显示 Top 分支与年度总结。

**故事 2｜看去年**

点页头年份 → 列出有数据的年份（最早一条记录所在年到今年）→ 选 2025 → URL 变为 `/history/2025`，所有区块按 2025 重算；没有数据的月份显示为空位而不是 0 柱。

**故事 3｜写一句年度总结**

在年度总结区输入一句话 → 失焦或点「保存」→ 保存成功；刷新或换年份再回来，文本仍在；清空后保存则回到空白提示。

**故事 4｜从年轮回到具体历史**

点某个月柱 → 进入 `/history` 并带入该月的时间范围与当前年；点 Top 分支行 → 进入该分支详情（P03）。

**异常与边界**

- 该年没有任何有效提交：四项指标为 0，12 个月全部显示空位，仍可写年度总结；页面提示「这一年还没有留下提交」并给「去今天」。
- 选择未来年份：不可选；年份列表只到当前年。
- 该年只有里程碑没有提交：四项指标仍为 0，但年度总结可写；不把里程碑计入提交数。
- 统计读取失败：保留页头与区块骨架，说明原因并可重试；不显示上一次的旧数字冒充当前结果。
- 年度总结保存失败：保留输入，提示重试；不关闭编辑态。
- 年份在 URL 中非法（非四位数字、超出数据范围）：回落到当前年，并更新 URL。
- 跨年瞬间（本地时间 1 月 1 日零点）：当前年变化，年份列表新增一年；已打开页面不自动跳转，刷新后按新年计算。

## 4. 界面与交互

对应页面：**P05**（`/history/:year`）。入口：P04 历程页头的「年轮」，以及 P06「我的」中与年度相关的入口不改。

### 4.1 页头与年份切换

- 页头显示「2026 年」与年份切换控件；可切换范围为本机最早记录所在年到当前年。
- 有数据的年份正常显示；无数据的年份仍可选，进入后显示空年轮。
- 切换年份只改 URL 与页面数据，不重置主题、密度、注解等偏好。
- 从 P04 进入时默认当前年；P04 的筛选与时间范围不影响年轮。

### 4.2 四项指标（R11）

| 指标 | 口径 | 展示 |
| --- | --- | --- |
| 提交数 | 该年 `commits.date` 落在该年且 `voidedAt == null` | 整数 |
| 活跃一级分支数 | 该年有有效提交的分支，归并到各自的一级祖先，按一级分支去重计数 | 整数 |
| 新开 | 该年 `branches.createdAt` 落在该年、非根分支、未删除 | 整数 |
| 收尾 | 该年 `branches.finishedAt` 落在该年且 `status=merged`、未删除 | 整数 |

- 放下不计入收尾；放下数量不在四项指标内，只在月回顾（V1-03）出现。
- 已归档分支的数据照常计入四项指标与其分布。
- 四项指标都是现算，不读缓存值。

### 4.3 12 个月分布

- 横轴 1–12 月，纵轴为该月有效提交数。
- 子分支提交归并到其一级祖先后再按月计数；同一提交只算一次。
- 当前年未到的月份显示为空位，不画 0 柱；已到但无提交的月份画 0 柱。
- 点某月进入 P04，并带入该月范围；该年整年范围由「今年 / 全部」档位承接。

### 4.4 分支分布与 Top 分支

- 一级分支占比 = 该一级分支（含其后代）在该年的有效提交数 ÷ 该年有效提交总数。
- 颜色沿用分支在树、泳道中的同一色相（K-03），不在年轮另起一套。
- Top 分支按该年有效提交数降序取前 5；每条显示分支名、提交数、占比；并列时按分支创建时间升序。
- 分支行显示该分支当前的「本分支直接待办完成进度」`taskDone/taskTotal`，并注明这是当前进度、不是该年进度。
- 已归档的一级分支仍出现在分布中，行样式按归档区分。

### 4.5 年度总结

- 每年一段文本，存 `year_reviews.note`；同一用户同一年只有一行。
- 默认显示为可点击的空白提示「写一句这一年」；点击进入编辑，两行高度，支持换行。
- 保存动作：失焦自动保存，或点「保存」；保存成功给一次轻提示，不弹窗。
- 清空并保存后删除该年的 `note` 内容（保留行或按实现删除行均可，读取时必须视为空）。
- 年度总结不参与任何统计，不影响徽章。

### 4.6 五种状态

| 状态 | 表现 |
| --- | --- |
| 空 | 该年无有效提交：四项指标为 0，月份全为空位，一句「这一年还没有留下提交」+「去今天」；年度总结仍可写 |
| 加载 | 保留页头、四项指标骨架、图表容器高度；数字与图表加载完成后不跳动 |
| 错误 | 统计读取失败：保留外框，说明原因 + 重试；年度总结保存失败：保留输入与编辑态 |
| 只读 | 年轮本身只读；仅年度总结可编辑；归档分支的数据只参与统计，不提供行内编辑 |
| 无权限或未登录 | 不适用；V1 无账号，年轮不要求登录 |

### 4.7 移动端

- 390 px：四项指标改为两列两行；12 个月图表在容器内横向滚动，保留纵轴刻度，不压缩成不可读的细柱。
- 分支分布与 Top 分支并为主列单列；年度总结在页面底部，键盘弹起时保存按钮可见。
- 年份切换用可横向滚动的年份条，不依赖悬停。

## 5. 数据与规则

| 表 | 字段 | 用途 |
| --- | --- | --- |
| `commits` | `branchId`、`sourceBranchId`、`date`、`at`、`voidedAt` | 提交数、月份分布、一级分支占比、Top 分支 |
| `branches` | `_id`、`parentId`、`path`、`depth`、`title`、`color`、`status`、`archivedAt`、`createdAt`、`finishedAt`、`deletedAt`、`taskTotal`、`taskDone` | 新开、收尾、一级祖先归属、颜色、进度 |
| `milestones` | `achievedAt`、`branchId` | 不参与四项指标；本 PRD 不读取 |
| `year_reviews` | `ownerId`、`year`、`note`、`createdAt`、`updatedAt` | 年度总结，唯一键 `[ownerId+year]` |

规则：

- R11 年轮：提交数、活跃一级分支数、新开、收尾按上表口径；月度图把子分支提交归并到一级祖先；分支分布按一级分支占比；12 月未开始画占位。
- R3 有效提交：所有年轮统计只算 `voidedAt == null` 的提交；已撤销提交不计入任何指标。
- R7 四计数：Top 分支行的进度直接读分支的当前 `taskDone` / `taskTotal`，不在年轮重算、不按年过滤。
- 一级祖先归属：沿 `parentId` 上溯到 `depth = 1` 的分支；根分支上的提交单独归入「我」一项，不进入一级分支占比的分母之外。若该年只有根分支提交，活跃一级分支数为 0，提交数照常显示，分布显示「我」一行。
- 根分支不参与「新开」计数（M02 口径）。
- 年份边界按业务日期 `date` 的 `YYYY` 判断，不按 `at` 的 UTC 年转换；跨时区以写入时记录的本地日期为准。
- `year_reviews` 每用户每年唯一；保存用 upsert，不产生第二行。
- 删除软删分支不计入新开与收尾。

## 6. 验收标准

1. 进入 `/history/2026` 时四项指标与直接按 `commits`、`branches` 现算的结果一致；撤销一条提交后刷新，四项指标与月度图同步减少。
2. 某年有 3 条一级分支产生过提交，其中一条的全部提交都来自其二级子分支：活跃一级分支数显示 3，月度图把子分支提交计入该一级分支。
3. 当年新建 4 条非根分支、收尾 2 条、放下 1 条：新开显示 4，收尾显示 2；放下不计入收尾。
4. 已归档分支在该年的提交仍计入提交数与分布；归档不改变历史数字。
5. 当前年未到的月份显示为空位，已到但无提交的月份显示 0 柱；两者视觉可区分。
6. 点某个月柱进入 P04 并带入该月范围；点 Top 分支行进入该分支详情。
7. 分支占比之和（含「我」一行时）为 100%，四舍五入误差不超过 1 个百分点；Top 分支按提交数降序且最多 5 条。
8. 在年度总结区写一句话并失焦，刷新后仍在；切到另一年再切回，文本仍属于原年份。
9. 清空年度总结并保存后，页面回到「写一句这一年」的空白提示；数据库中该年不再有非空 `note`。
10. 选择无数据的年份：四项指标为 0，月份全部为空位，提示可写年度总结；未来年份不可选。
11. 把 URL 改为非数字或超出范围的年份，页面回落到当前年并修正 URL。
12. 人为使统计读取失败：页面保留外框与骨架并提示重试，不显示旧数字；使总结保存失败：输入与编辑态保留。
13. 390 px 下 12 个月图表可横向滚动，四项指标两列两行，年度总结可完整编辑。

## 7. 依赖与阶段、未决问题

- 阶段：V1。
- 依赖：M06（历程与提交口径）、M08（收尾写 `finishedAt`）、V1-01（放下与归档，影响分布样式）；`year_reviews` 表随本 PRD 启用。
- 后续消费：V1-03 年度分享图直接复用本 PRD 的四项指标、月度分布与分支占比；V1-05 的「第一年」「年轮有痕」等徽章不依赖年轮页面，但展示口径一致。
- 冲突与处理：
  - `PAGE-DATA-CROSSCHECK` 把第二项写成「活跃分支数」，按 `commits.branchId` 去重；`TECH-ARCHITECTURE` R11 写「活跃一级分支数」。以 R11 为准，本 PRD 按一级祖先归并去重。
  - `PAGE-DATA-CROSSCHECK` 的年轮总结字段写作 `text`，且曾按「无表无字段」判缺；0.12 已定为 `year_reviews.note`，本 PRD 按 0.12。
  - `PAGE-DATA-CROSSCHECK` 的 D10 把「新开」限定为非根分支，与 M02「根不计入新开」一致，本 PRD 沿用。
- 未决问题：
  - 年度总结的长度上限与是否允许换行未定；当前按两行高度、允许换行、不设硬上限处理。
  - 年度总结是否需要在导出文件中随 `year_reviews` 一起导出：按 J-03「设置与相关历史」的口径应包含，需在 V1-06 的备份包结构中确认。
  - 年轮页是否显示「该年放下数」：F-05 未要求，本 PRD 不显示；月回顾（V1-03）会显示放下。
