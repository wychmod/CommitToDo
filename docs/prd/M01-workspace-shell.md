# M01 工作区底座、外框与偏好（MVP）

## 1. 背景与目标

所有页面都长在同一个工作区外框上。本 PRD 交付「打开就能用」的底座：无账号、纯本机、断网可用；四个一级入口与桌面/窄屏导航；主题、树密度、注解三个偏好；每页统一的空状态；以及「不登录也能用完整 MVP」的产品承诺。

目标：用户首次打开 `/today` 时，即使没有任何业务数据，也能看到完整外框、明确空态和一个可执行动作；刷新后偏好保留；断网后所有已载入页面继续可用。

## 2. 范围与非目标

**范围**

- L-01 无账号可用：不登录、不联网、不清浏览器数据时全部 MVP 功能可用；注册/登录入口不出现在任何阻断路径。
- J-01 本地优先：读写先落本机，云端不可用不影响操作；MVP 无云端依赖。
- A-03 空状态引导：每个页面无数据时一句说明 + 一个可用动作。
- I-01 一句话注解：分支是什么、合并是什么、里程碑与提交的区别、停滞虚线为什么是虚线；首次自动显示，之后折叠为小图标；同一概念全产品只有一种说法。
- I-02 注解开关：关闭 / 只显示一次（默认）/ 始终显示，全产品唯一开关。
- K-01 树密度：紧凑 / 舒适；调树行高（32 / 48 px）、列表行高（36 / 44 px）、节点旁是否显示日期；默认舒适；切换不重置树的展开状态。
- K-02 明暗主题：浅色（默认）/ 深色，只由用户手动切换。
- P01–P08 的应用外壳、一级导航、二级页面返回恢复、桌面与窄屏布局。
- P07 设置页（MVP 部分）。

**非目标**

- 不做账号、登录、找回、同步；这些在 V2-01、V2-02。
- 不做字号调节（与 `TECH-ARCHITECTURE` 0.12 删除 `settings.fontScale` 冲突，按文档不实现，见 §7）。
- 不做“跟随系统”主题。
- 不定义各页面的业务内容与数据写入，只定义外壳、状态容器与偏好。
- 不改表结构；只消费 `settings` 与 `localStorage`。

## 3. 用户故事与主流程

**故事 1｜第一次打开，不想注册**

打开任意 MVP 路由 → 直接进入工作区，看到完整导航和当前页空态 → 按空态动作开始记录 → 全程没有登录弹窗、没有“请先登录”。

**故事 2｜写着写着断网了**

已载入工作区后断网 → 继续添加、完成、编辑、切换页面 → 刷新页面（资源已缓存）仍可进入 → 所有操作只落本机，不出现“同步失败”。

**故事 3｜晚上想用深色**

进入 `/settings` → 主题选「深色」→ 全站立即切换并写入本机 → 刷新后仍为深色 → 系统主题变化不影响应用。

**故事 4｜树太松，想一屏多看几行**

`/settings` → 树密度选「紧凑」→ 分组树行高变 32 px、列表行高 36 px、节点旁日期隐藏 → 返回分支页，原展开状态保持不变。

**故事 5｜看不懂“停滞虚线”**

首次进入历程 → 注解自动出现一句解释 → 关闭后折叠为小图标 → 之后点击图标再看；若开关设为「关闭」，则任何页面都不自动出现。

**异常与边界**

- 本机存储不可用（隐私模式、配额耗尽、库打开失败）：保留顶栏与导航，主区说明「本机数据暂时无法读取」并提供「重试」；不得静默清空或新建空库覆盖。
- 偏好写入失败：界面保持用户刚选的值并提示未保存，允许重试；不回滚到旧值造成跳动。
- 直接访问二级页面且无上一页：返回落到该页所属一级入口，不出现空白历史栈。
- 窄屏旋转或改变宽度：导航在顶栏 + 底部之间切换，当前页与滚动位置保持。
- 用户从未设置过主题：按浅色渲染，不读取 `prefers-color-scheme`。

## 4. 界面与交互

### 4.1 应用外壳与导航

| 项 | 规则 |
| --- | --- |
| 桌面 | 顶栏 + 左导航；一级入口「今天 / 分支 / 历程 / 我的」 |
| 窄屏 | 顶栏 + 底部导航；四个入口保持同序 |
| 选中态 | 分支详情继承「分支」；年轮继承「历程」；设置与数据备份继承「我的」 |
| 二级返回 | 恢复原页滚动位置、筛选与树展开状态；无历史时回所属一级入口 |
| 首页与认证 | 使用独立外壳，不显示工作区导航 |
| 页面骨架 | 加载时保留顶栏、导航与内容区基本布局，不用整屏 spinner |

### 4.2 P07 设置

分区顺序：外观 → 注解 → 数据与备份入口。

| 控件 | 选项 | 默认 | 生效方式 |
| --- | --- | --- | --- |
| 主题 | 浅色 / 深色 | 浅色 | 立即全站生效，写 `settings.theme` |
| 树密度 | 紧凑 / 舒适 | 舒适 | 立即生效，写 `settings.treeDensity`；不重置树展开状态 |
| 注解 | 关闭 / 只显示一次 / 始终显示 | 只显示一次 | 立即生效，写 `settings.annotations` |
| 数据与备份 | 进入 `/data` | — | 跳转，不在此页展示备份明细 |

不出现「跟随系统」。V2 的账号与同步分区不在本 PRD 交付，P07 在本阶段不显示这两个分区。

### 4.3 空状态（A-03）

每个页面统一结构：一句当前说明 + 一个主行动作；不使用插画堆砌，不出现两个同等权重的按钮。

| 页面 | 说明要点 | 动作 |
| --- | --- | --- |
| 今天 | 今天还没有要做的 | 记一笔（打开快速添加，见 M03） |
| 分支 | 还没有分支，待办可以直接记在「我」上 | 新建分支（见 M02） |
| 分支详情 | 这条分支还没有待办 | 添加待办（见 M04） |
| 历程 | 完成第一条待办后，这里会出现你的第一段路 | 去今天（见 M03） |
| 年轮 | 今年还没有提交 | 去今天（V1 页面，V1-02 交付） |
| 我的 | 还没有获得徽章 | 去今天完成一条（M11 交付徽章列表） |
| 设置 | 不适用 | — |
| 数据与备份 | 还没有可导出的数据 | 去今天（M10 交付导出） |

### 4.4 五种状态

| 状态 | 本 PRD 的表现 |
| --- | --- |
| 空 | 按 §4.3；外框与导航完整 |
| 加载 | 顶栏、导航、内容区骨架保留；偏好类内容不闪烁 |
| 错误 | 存储不可用或偏好写入失败时，就地说明原因 + 重试；不清空数据 |
| 只读 | 本 PRD 不产生只读页；只读由 M04/M05/V1-01 定义 |
| 无权限或未登录 | 不适用。MVP 无账号，任何页面不得要求登录；`/auth/*` 路由在 MVP 不暴露入口 |

### 4.5 移动端退化

- 390 px：左导航并入底部导航；页面主列单栏；详情与编辑使用全屏面板，保留明确关闭入口。
- 设置页控件单列排布，点击区域不小于 44 px；切换后不跳回顶部。
- 底部导航固定时，页面底部留出安全间距，最后一个可点元素不被遮挡。

### 4.6 注解（I-01 / I-02）

- 四个概念各一句人话，文案由统一词表生成；同一概念在树、详情、历程中不得出现第二种说法。
- 首次到达相关页面自动显示一次；用户关闭后折叠为小图标，点击可再次展开。
- 开关为「关闭」时不自动显示、不显示小图标；为「始终显示」时每次进入相关页面都展开。
- 注解不遮挡主操作；展开与收起不改变页面布局高度导致内容跳动（使用浮层或预留位）。

## 5. 数据与规则

| 数据 | 表 / 位置 | 字段 | 说明 |
| --- | --- | --- | --- |
| 偏好 | `settings`（单行，主键 `id`） | `theme`、`treeDensity`、`annotations`、`rev`、`updatedAt` | 写入即生效；导出时随全量数据带走 |
| 注解已展示标记 | `localStorage`，key 为 `hint.<id>.seen`（`id` 取四个概念之一） | 是否已展示过 | 不新增 `settings` 字段；丢失后该注解重新自动展开一次，可接受 |
| 会话级 UI 状态 | `localStorage` | 最近视图、滚动位置、筛选与展开状态 | 不放领域数据；丢失不影响业务 |
| 身份 | — | `ownerId` 留空或写本地设备 ID | MVP 无账号，不做登录校验 |

规则：

- R19：主题只有 `light` / `dark`，初始 `light`，只由用户手动切换；不读取 `prefers-color-scheme`。
- K-01 密度三件事必须同时生效：树行高、列表行高、节点旁日期；切换密度不得重置树展开状态。
- 无账号承诺（L-01）：MVP 所有页面可见可写；登录入口不得出现在任何阻断路径。
- J-01：所有读写先落本机；MVP 不发起网络请求即可完成全部功能。
- 空态动作必须指向本阶段真实存在的入口，不出现“敬请期待”。

## 6. 验收标准

1. 清空浏览器数据后打开 `/today`，直接进入工作区，看到空态与「记一笔」；全程无登录弹窗、无注册拦截。
2. 断网后刷新已载入的 MVP 页面，外框、导航、当前页与已载入内容仍可用；新增/完成操作不报“网络错误”。
3. `/settings` 切换深色，全站立即变深；刷新后仍为深色；系统切换深浅色时应用不变。
4. `/settings` 切换紧凑，分组树行高为 32 px、列表行高为 36 px、节点旁日期隐藏；返回分支页，原先展开的分支仍展开。
5. 刷新页面后主题、密度、注解三项与刷新前一致。
6. 注解默认「只显示一次」：首次进入历程看到停滞虚线解释，关闭后变成小图标；再次进入不自动展开。
7. 注解设为「关闭」后，四个概念均不自动出现；设为「始终显示」后每次进入相关页面都展开。
8. 桌面 1440 px 与窄屏 390 px 下，四个一级入口、选中态、二级返回恢复滚动/筛选/展开均符合 §4.1。
9. 直接访问 `/branches/:id` 后点返回，落到 `/branches`；访问 `/settings#account` 在 MVP 不出现账号内容或错误页。
10. 人为制造存储不可用（如禁用 IndexedDB）时，页面给出可读错误与「重试」，不出现空白页，不清空已有数据。

  - P07 的账号与同步分区归 V2-01，本阶段不显示。

最值钱的回归用例：`annotation-visibility.test.ts` 的「一个概念已看过不影响另一个概念」，守的是四个概念共用一个「已展示」标记的 bug——一旦共用，看过分支注解后里程碑注解就永远不再自动出现；手工验收通常只盯一个概念，很难按「先看 A 再看 B」的顺序复现。`nav-selection.test.ts` 的「`/data` 与 `/settings` 归『我的』」，守的是新增路由忘记映射导致导航整条失去选中态的 bug；从导航点进去的手工路径看不出问题，只有直接访问或深层路径才暴露。

### 8.3 只能人工验收

1. **主题切换的全站一致性**：前置为浅色主题、工作区有分支与待办；在 `/settings` 切到深色；判定为顶栏、导航、树、面板与空态同时变深，无残留浅色块，切换瞬间不闪白；1440 与 390 各一次。为什么不能进单测：断言的是样式表级联后的渲染色，`jsdom` 不计算样式。
2. **密度切换后的行高与展开保持**：预置 3 条一级分支并展开其中两条；切到紧凑；判定为树行 32 px、列表行 36 px、节点旁日期不可见，返回分支页两条仍展开且滚动位置不跳；1440。为什么不能进单测：行高来自真实布局，展开状态保存在浏览器历史与 UI 状态里。
3. **注解不遮挡与不跳动**：预置一条带注解的历程页；进入后展开再关闭；判定为注解不覆盖主操作区，展开与收起不使下方内容位移；1440 与 390。为什么不能进单测：测的是占位与遮挡关系，纯函数无法表达。
4. **二级返回恢复滚动与筛选**：在分支页滚到中段、展开 L2 后进入详情再返回；判定为滚动位置、筛选与展开状态均复原；1440 与 390。为什么不能进单测：依赖真实浏览器历史栈与滚动容器。
