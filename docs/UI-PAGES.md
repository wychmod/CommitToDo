# CommitToDo 页面与交互规格

**状态：2026 年 11 月 22 日更新 Web 认证参考。** 首页和分组树沿用确认稿。原图册包含 **12 个页面与 38 个补充视图和操作状态**，每组有明暗两稿。认证与账号设置采用新的配套画稿。画稿用于核对界面和示例状态，功能阶段、数据与账号边界按产品框架和技术架构落实。[设计交接入口](DESIGN.md) · [产品框架](FRAMEWORK.md) · [技术架构](TECH-ARCHITECTURE.md) · [原图册](../design/index.html) · [Web 认证画稿](web-auth/DESIGN.md)

尺寸、配色和分支符号统一取自视觉规范。导航、菜单、抽屉、表单和反馈复用同一套组件。首页演示与应用页面各有时序定义。[视觉规范](UI-VISUAL.md) · [组件规格](UI-COMPONENTS.md) · [首页动效](HOMEPAGE-MOTION.md) · [应用动效](UI-MOTION.md)

## 1. 页面与导航

桌面工作台采用顶栏和左导航，窄屏改为顶栏和底部导航。四个一级入口为「今天、分支、历程、我的」。分支详情继承「分支」选中态，年轮继承「历程」，设置与备份继承「我的」。二级页面返回时恢复原页滚动、筛选和展开状态。首页和认证采用独立外壳。

| 编号 | 页面与画稿 | 路由 | 首发阶段 | 页面内容和去向 |
| --- | --- | --- | --- | --- |
| P00 | [首页](../design/index.html#p00-home) | `/` | MVP | 首屏工作台演示、三块内容、分组与时间树、使用场景。页头「登录」进入 `/auth/login`，「打开工作区」与页尾「打开 CommitToDo」进入 `/today`；首屏「查看示例」定位页内演示。 |
| P01 | [今天](../design/index.html#p01-today) | `/today` | MVP | 逾期、今天、无截止日期三组，最近提交、停滞提醒、快速添加和全部待办入口。周回顾按周期出现。 |

| P05 | [年轮](../design/index.html#p05-year) | `/history/:year` | V1 | 年份切换、提交和分支指标、月度分布、新开和收尾结构、年度总结与分享图。 |
| P06 | [我的](../design/index.html#p06-me) | `/me` | MVP | 已获徽章定位历程、进入设置与数据备份。V1 增徽章墙，V2 增账号入口与帮助。 |
| P07 | [设置](../design/index.html#p07-settings) | `/settings` | MVP | 默认浅色，深色只由用户手动切换（**不提供「跟随系统」**，画稿该选项为遗留）；紧凑／舒适、注解选项、数据与备份入口。V2 增账号与同步分区。 |
| P08 | [数据与备份](../design/index.html#p08-data) | `/data` | MVP | JSON 导出、从文件导入（核对摘要后整体替换，导入前留存当前数据副本）。V1 增本机快照（每日首次打开自动备份、保留 7 份）与按快照恢复、按匿名设备归档的异地明文备份。 |
| P09 | [登录](web-auth/DESIGN.md#登录) | `/auth/login` | V2 | 独立登录页，提供创建账号、找回密码与打开本机工作区的入口。认证成功回到有效的应用内 `next`，缺省到 `/today`。 |
| P10 | [注册](web-auth/DESIGN.md#创建账号) | `/auth/signup` | V2 | 沿用登录的双栏构图，提供返回登录和打开本机工作区的入口。 |
| P11 | [找回密码](web-auth/DESIGN.md#找回密码) | `/auth/recover` | V2 | 同一路由承载填写邮箱、检查邮箱、设置新密码三步。三步共享认证外壳，均保留返回登录入口。 |

- `/today/all` 是今天的全部待办视图，`/branches?view=archived` 是 V1 的归档视图。徽章详情、待办详情、提交详情与各类操作沿用所属页的面板或弹层。V2 账号、同步等分区可通过 `/settings#account` 与 `/settings#sync` 定位。
- 已载入的 MVP 工作台在断网后仍可完整使用，首页和其他页面入口遵循同样的本机优先原则。MVP 只做 JSON 导出与从文件导入；V1 起才提供本机快照、按快照恢复与异地备份，均按匿名设备工作，异地文件是带 `schemaVersion` 的明文 JSON。不做端到端加密，数据明文存储，安全边界靠服务端权限规则。首页提供独立登录页入口，账号相关功能也可在具体位置提示登录；打开本机工作区始终可用。
- Web 认证采用独立外壳。顶栏左侧是品牌，右侧是「打开本机工作区」。桌面左侧放表单，右侧显示静态时间树、勾选便签与提交回执。页内换表单或找回步骤时沿用同一右侧场景。窄屏呈现单列表单，保留顶栏的本机工作区入口。邮箱与密码是画稿示例渠道，实际渠道、找回方式、数据归属和冲突处理按 V2 技术决策落实。站内登录从行内提示进入独立页，冲突稿用于查看两次修改与分支留痕。[Web 认证画稿](web-auth/DESIGN.md) · [技术架构 §4.6、§6](TECH-ARCHITECTURE.md)

### 1.1 首页形态（P00）

基准图为 [p00-home-light.png](../design/images/p00-home-light.png)（2026-11-20 19:33 敲定，793×1983，1512 宽折合约 3800px），暗色版 [p00-home-dark.png](../design/images/p00-home-dark.png) 与之对应。首页是**分段场景**，共七段：

| 段 | 区块 | 内容 |
| --- | --- | --- |
| 1 | 首屏 | 品牌导航、登录文本链接与「打开工作区」入口、双行标题（「今天」着色）、副文案、「查看示例」页内定位；居中的今天清单工作台，左侧黄色便签、右侧叠放蓝色回执 |
| 2 | 三块内容，一个工作区。 | 三张功能卡：今天 / 分支 / 历程，各一枚图形 |
| 3 | 分段导航 | 今天 / 分支 / 历程 三项，激活项细线滑到对应项，随滚动追踪当前区块 |
| 4 | 一处放下，沿路找回。 | 上排为今日清单与历程柱状图两张产品窗，下方为横跨内容区的分支面板，右侧展示「我」及三个分支 |
| 5 | 沿着分支，找回每一次完成。 | 时间树产品窗：三条一级泳道、分叉与合回、选中节点 |
| 6 | 生活里，处处能用。 | 三张场景卡：做作品 / 跑一公里 / 继续阅读 |
| 7 | 今天就开一页。 | 全页唯一实心 CTA、页脚 1px 与链接 |

**线的规则**：分支线只在单个演示窗内出现，随所在区块结束而收束；区块之间用整幅背景带和标题分隔，**不画贯穿整页的线，也不跨区块出画重入**。首屏点线止于「已提交」回执，第 4、5 段的线各自独立。移动端按同一顺序单栏堆叠，删去右缘注解与段内左右双栏，产品窗左右各裁 24px，分段导航横向可滚。

## 3. 布局、状态与验收

- **桌面与窄屏。** 参考宽度为 1440 px，另验 390 px。今天的侧栏在窄屏并入主列。分组树保留层级缩进、状态、展开与行尾操作，次要时间或统计可进入详情。应用历程在窄屏用纵向时间线表达相同的分支、日期与汇合。首页的示例图可以在图表容器内横向查看，两处都保留页面自然纵向滚动。桌面详情和编辑常用侧栏，移动端用全屏面板保留操作与关闭入口。
- **反馈状态。** 空页给一句当前说明和一个可用动作。加载保留基本布局。错误在相关字段或动作旁解释原因并提供重试，保存失败保留输入。从文件恢复的校验、备份或写入失败时保留现有数据。跨日提交和已归档待办显示只读原因；写入当日的提交纠错仍按产品规则处理。状态用文字或形状配合颜色表达。
- **键盘与弹层。** 名称、展开和更多各自可操作并有独立可见焦点。打开弹层后焦点进入，关闭后返回触发控件，`Esc` 关闭未提交的菜单和弹层。阻断型确认对话框限制焦点在内，屏幕阅读器可识别标题、说明、禁用原因和结果。节点提供名称与日期的可读入口。
- **核心链路。** 浏览器加载应用资源后，在业务数据为空的本机工作区断网进入「今天」，完成一条归于根分支的待办，确认只生成一条提交。通过回执定位同一条真实历程节点，保留用户原筛选设置。当天撤销后，任务、有效时间线和计数同步更新，跨天锁定。另验根分支、三层树、同级重复名、非法移动和两步收尾。
- **数据和阶段。** 从导出文件在另一干净浏览器恢复真实历程。校验失败、备份失败和取消时原数据仍可打开。分别检查 MVP、V1、V2 的功能入口，本机流程从头到尾可直接使用。V1 备份与 V2 同步各使用其对应文案。
- **设计验收。** 对照现行浅深画稿逐页检查主操作、活动导航、两套主题、长名称、窄屏和系统减少动效。业务状态用功能框架的数据跑通，再检查视觉反馈。[视觉规范](UI-VISUAL.md) · [组件规格](UI-COMPONENTS.md) · [首页动效](HOMEPAGE-MOTION.md)
