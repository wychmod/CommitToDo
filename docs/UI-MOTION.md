# CommitToDo 应用页面动效规范

**范围为 P01–P11 和 38 个补充视图及操作状态。** 明暗主题共用时序。页面的路由、数据、控件和阶段沿用现行规格；V1／V2 条目随对应功能上线。营销首页 P00 使用独立编排。[页面与交互规格](UI-PAGES.md) · [视觉规范](UI-VISUAL.md) · [组件规格](UI-COMPONENTS.md) · [首页动效](HOMEPAGE-MOTION.md)

## 1. 共用时序

动作先回答「刚才发生了什么」，再帮用户看清新位置。代表性反馈是勾选后的回执、展开时接上的分支线、历程里圈出的目标节点。

| 用途 | 时长 | 动作和终态 |
| --- | --- | --- |
| 按下、选中、勾选、菜单 | 120 ms `--duration-micro` | 在当前控件内更新勾号、底色或描边。锚定菜单从触发处淡入，位移最大 4 px。 |
| 行或列表改变、抽屉、对话框 | 200 ms `--duration-standard` | 行在原位收展或淡入。桌面侧栏从右侧最后 16 px 入场，移动端全屏面板最多上移 8 px。居中对话框最多上移 6 px，遮罩与容器同时进入。 |
| 一次性进入、连续图形反馈 | 320 ms `--duration-entry` | 每段总时长最多 320 ms，子动作可重叠。只用于首次需要解释的新画面，例如时间树第一次有数据或登录壳里的便签插画。 |
| 退出 | 120 ms | 就地淡出或反向移动。结束后释放遮罩和滚动锁。 |
| 减少动效 | 0 ms | 直接应用最终布局、颜色和可见状态。使用指定位置立即定位，保留所有操作及反馈。 |

入场与状态变化用 `--ease-enter: cubic-bezier(.2,0,0,1)`，退出用 `--ease-exit: cubic-bezier(.4,0,1,1)`。只有这两条曲线，不新增弹簧、回弹或自定义贝塞尔。令牌记录四档时长与两条缓动。动效的开始、取消和结果由页面及组件状态控制。[时长与缓动令牌](../design/design-tokens.json)

**320 ms 是应用内上限，营销首页 P00 不受此约束。** P00 的首屏编排 1.4 s、时间树 620 ms 属于演示表演，由 [首页动效](HOMEPAGE-MOTION.md) 单独定义；两者不共用计时表，也不互相引用时长。应用页面里出现超过 320 ms 的单段动画即为缺陷。

### 回执状态机

完成、保存、恢复等写入成功后出现回执。四种回执共用同一状态机，只改变文案与是否带操作：

| 阶段 | 时长 | 行为 |
| --- | --- | --- |
| 出现 | 200 ms | 在触发位置就地展开并淡入，同时收起被完成的源行。不遮挡、不居中、不抢焦点。 |
| 停留 | `--receipt-hold: 10 s` | 保持可操作。停留期内提供「撤销」与「在历程查看」。指针悬停或焦点落在回执内时暂停计时。 |
| 收起 | 200 ms | 反向收起，源位置让给下一条。收起后不保留占位。 |
| 归档 | 立即 | 内容进入目标位置的常驻处：完成类进「最近提交」，保存类不留痕，恢复类进操作记录。归档后仍可从该处回看。 |

- **撤销窗口与数据层一致。** 回执上的「撤销」只在写入当日有效；跨过本地零点后按钮消失，改为只读说明「当天可撤销，已锁定」。这条 UI 映射对应 [功能框架](FRAMEWORK.md) 的 E-02，不额外定义时限。
- **同一位置只有一条回执。** 上一条未收起时再次触发，直接把上一条归档到常驻处，再用新内容替换，不做堆叠、不做队列。
- **焦点不进入回执。** 键盘用户可用 `Tab` 到达回执内的操作；行被移除时焦点按上一节的规则落到同组下一条，而不是落到回执。
- **失败不进回执。** 写入失败就地显示错误行，保留源行、输入与焦点，不出现回执。

### 状态播报清单

只有下列结果进入 `aria-live="polite"` 的播报区，且每条只播一次、用结果句而不是过程句。其余视觉反馈不播报。

| 场景 | 播报文案示例 |
| --- | --- |
| 待办完成 | 「完成：完成线框初稿。已生成提交。」 |
| 撤销完成 | 「已撤销完成，待办已恢复。」 |
| 分支收尾 | 「已收尾：产品设计。47 条提交并入工作。」 |
| 归档 / 取消归档 | 「已归档：产品设计。」/「已恢复：产品设计。」 |
| 从文件恢复完成 | 「已恢复，共 12 条分支、120 条提交。」 |
| 备份或同步失败 | 「备份失败。原数据未受影响。」 |
| 登录成功 | 「已登录。回到刚才的页面。」 |
| 找回邮件已发送 | 「如果该邮箱存在，重置链接已发送。」 |

- **不播报**：悬停、展开折叠、筛选切换、页码变化、输入校验中间态、菜单打开。它们由控件自身状态与焦点表达。
- **不重复**：同一结果在回执、列表和顶栏同时更新时只播报一次，取最靠近触发处的那个。
- **阻断型错误**用 `role="alert"` 而非 polite，且只在首次出现时播报。

### 状态与焦点

- **导航。** 保持顶栏、侧栏或底部导航稳定。一级入口切换时立即更新选中项，新内容就位后可用 120 ms 就地淡入。浏览器返回恢复原滚动和展开状态。页内定位由用户触发，有明确目标，只移动必要距离。
- **等待、成功和失败。** 保存中用按钮文字或就地状态提示。确定的真实进度可逐步更新；未知进度用静态的处理中说明。成功以业务写入或服务响应为准。失败在相关字段或动作旁说明原因，输入、焦点和尚可读取的数据保留。
- **连续操作。** 同一区域保留最后一次有效操作的目标状态。连续展开、折叠、换筛选或返回时，取消上一段的剩余动画。组件可以直接呈现最终状态，业务提交次数由交互与事务控制。
- **浮层。** 菜单、侧栏和对话框打开后，焦点进到可用动作、需要填写的字段或可读标题。模态留住焦点并限制底层滚动。可关闭的浮层支持 Esc；关闭后回到触发处，触发项已经移除时回到相邻可操作行或分区标题。
- **可读反馈。** 焦点轮廓立即出现。成功、错误、选择、锁定和归档都用可读文字与控件状态表达。状态公告只播报重要结果。减少动效、脚本尚未接管或入场动画未触发时，界面直接可读。

## 2. 按页面执行

### P01 今天 · MVP

- 从「记一笔」或清单添加时，新行在对应分组出现，120 ms 淡入。逾期、今天、无截止日期组按用户操作就地展开或收起，200 ms 内完成。保留其他组的展开状态。收起后露出的第一条占用固定位置，完成后由下一条接上。
- 点完成时即时给出控件回应。写入成功后在 120 ms 内画出勾号，约 200 ms 内收起完成行并显示带任务名的提交回执。回执的出现、停留 10 s、收起与归档按第 1 节的回执状态机执行。最近提交和计数同次更新。由回执「在历程查看」定位同一条实际提交。
- 键盘触发且当前行离开列表时，焦点移至同组下一条可操作待办；组内已空时落到组标题或添加入口。用户可继续 Tab 到回执操作。失败保留原待办、原分类和焦点，并给出重试原因。纠错成功后按现有规则恢复待办和时间树。[今天画稿](../design/index.html#p01-today)

### P02 分组树 · MVP

- 路由进入后原样呈现分组。点左侧展开控件时，箭头 120 ms 转向展开状态；子行和局部连线约 200 ms 显出，父行、相邻分组和触发控件保持视觉锚点。折叠时反向收起该组。该行的名称、展开、更多分别响应。
- 点名称进入分支详情，保持工作台壳层。点行尾「更多」或通过右键／长按打开锚定菜单，按视口边缘调整方向，按 120 ms 规则出现。页头「新建分支」打开右侧栏。
- 新建、移动、合并、归档等成功后，仅更新受影响的分组和计数。新建时定位新行；移动时在新归属下强调一次；收起或删除导致当前行离开时，焦点退到父行或同级可操作行。选中态用分支颜色的淡底与边框，和键盘焦点分别保留。[分组树画稿](../design/index.html#p02-branches)

### P03 分支详情 · MVP

- 点分支目标时，用 120 ms 将原位文本切到输入状态，焦点进入字段。保存成功后同位置切回显示态。失败保留草稿并给就地错误；只读时呈现原因。
- 页内「待办／提交／子分支／里程碑」由用户主动定位，选中指示在 120 ms 内切换。滚动跟随阅读位置更新指示。返回分支树时恢复原位置。
- 完成待办与 P01 使用同一回执逻辑。更新直接待办进度条时，从已有比例到新比例用 200 ms。提交和里程碑新增后只强调实际新增行，子分支名单局部更新。收尾从右上「更多」进入同一确认流程。[分支详情画稿](../design/index.html#p03-branch-detail)

### P04 历程 · MVP

- 进入页面时立即呈现日期轴、泳道名称和可操作控件。首次展示可用数据时，在 320 ms 内用短描线和节点淡入交代父轴、子线与事件。再次进入、浏览器返回或直接定位具体记录时呈现现有图形。
- 范围或分支筛选改变后，按新的日期比例和可见泳道布局，受影响内容 200 ms 内淡入。点分支展开时仅更新相关泳道。主动缩放或平移由手势控制，选中状态保留到目标被过滤掉或由用户切换。空结果在图表内显示解释和可用入口。
- 回执、徽章与搜索直达时，先等实际目标加载，再临时展开、定位并用 120 ms 显示目标环与标题。导航前的筛选偏好保留。原事件已撤销或找不到时说明原因。图中圆点、汇合点或菱形被选中后打开对应详情，移动端以纵向列表定位。
- 合回图形只出现在已成立的合回时点，连续超过规定天数才显示停滞虚线和天数。高亮环保留分支色中心；状态变化以实际节点和标签表达。[历程画稿](../design/index.html#p04-history)

### P05 年轮 · V1

- 切换年份时，年份控件先在 120 ms 内更新选中态。新年份数据就绪后，数字、月度分布和分支排行在既有壳层内 200 ms 切换。指标立即显示真实值，月度分布和时间轴一起使用对应年份。
- 鼠标、触控或键盘查看月份时只强调当前月份。往年总结显示只读，当年总结在原位编辑，保存和错误反馈都留在该处。
- 点分享时打开预览。分支名称开关 120 ms 更新，画布在 200 ms 内切换到新内容，保持预览尺寸。下载结果按实际生成状态反馈。[年轮画稿](../design/index.html#p05-year)

### P06 我的 · MVP，V1／V2 扩展

- 徽章按已有结果展示。聚焦或选中在 120 ms 内显示轮廓。MVP 选徽章直达原事件；V1 进入徽章墙和详情。原事件已撤销时显示授予快照与文字原因。
- 数据与备份、设置采用稳定的导航切换。最近备份时间、V2 账号及同步标签随真实状态就地更新，成功或异常只出一次可读提示。[我的画稿](../design/index.html#p06-me)

### P07 设置 · MVP，V1／V2 扩展

- 主题切换直接生效，设置项 120 ms 更新选中状态。默认白天（浅色），深色由用户手动切换。视觉切换集中在主题值，避免大面积明暗过渡带来的闪烁。
- 树密度、注解开关在当前行即时更新。切换密度时保留分组、展开、选中项和当前滚动锚点。V1 字号变化可自然重排，保存或报错在原设置行显示。
- V2 账户或同步分区切换时保留公共壳。需要登录的控件在该行提供可读提示和链接。[设置画稿](../design/index.html#p07-settings)

### P08 数据与备份 · MVP，V1 扩展

- 手动本机备份后，实际写入的新快照行在原列表 200 ms 内显出，最近备份标签即刻更新。导出按文件生成结果显示「已生成」或可重试的错误。状态说明静态可读。
- 从文件恢复按「校验 → 摘要 → 确认 → 备份当前数据 → 替换结果」展示，每步由实际状态推进。重新选文件后以新文件的校验为准。成功后刷新工作区，有原数据时显示最近恢复前副本的下载入口。校验、备份或替换失败时，保留原数据和当前可读上下文。
- V1 本机快照恢复复用摘要与确认。异地备份显示真实上传或下载状态，在当前操作行提示重试。[数据与备份画稿](../design/index.html#p08-data)

### P09 登录 · V2

- 首次进入认证壳时，现有便签和回执插画可做一次 320 ms 以内的局部淡入，偏移最大 4 px。表单、标题和「打开本机工作区」立即可用。已在认证壳内切换路由时沿用插画静态状态。
- 输入聚焦即时描边。显示密码仅切换输入状态，图标 120 ms 更新，保留内容与输入位置。提交时按钮文字表示进行中；失败说明与有关输入项相邻，服务错误在表单顶部说明。成功后按有效的应用内返回路径导航，缺省进入「今天」。[登录画稿](../design/index.html#p09-login)

### P10 注册 · V2

- 从登录进入时，只在表单列切换内容，120 ms 淡入。密码要求与强度显示在相关字段旁，状态按实际输入更新。条款选中与按钮可用状态在当前处即时变化，提交期间保留布局和退出路径。
- 字段校验失败后提示第一个需修正的字段，保留已填内容及返回登录入口。成功提示出现在可信的服务结果后。邮箱路径是当前视觉示例。[注册画稿](../design/index.html#p10-signup)

### P11 找回 · V2

- 三步沿用同一认证壳。发送、检查邮箱、设置新密码的当前步骤随真实流程更新，120 ms 切换指示、200 ms 切换右侧内容，新标题获得焦点。
- 提交邮箱后显示统一结果，重发按钮用等宽数字保留尺寸。倒计时到可重发时更新文字并公告一次。有效重置链接直接进入设置新密码；过期时提供重新发送。主按钮按返回结果显示成功或错误。
- 实际认证渠道沿用 V2 决策。这里的发送、重置和倒计时均对应邮箱方案画稿。[找回画稿](../design/index.html#p11-recover)

| [B02 新建一级分支](../design/index.html#b02-branch-new) | 200 ms 打开侧栏，首字段获得焦点。预设色相的选中标记 120 ms 更新。 | 保存成功后关侧栏，在根下显示新分组。输入或校验有误时保留侧栏、焦点和字段。 |
| [B03 新建子分支](../design/index.html#b03-branch-new-child) | 同一侧栏预填父分支及继承色相。 | 成功后展开真实父行，新子行 200 ms 内就位。权限或层级错误就地提示。 |

| [B06 收尾 · 选择去向](../design/index.html#b06-branch-finish) | 打开第一步，120 ms 切换待办去向与留树选项。 | 需要确认影响时进入下一步，同一对话框内 200 ms 换内容，选择结果保留。 |

| [B08 放下分支](../design/index.html#b08-branch-pause) | 表单入场和原因字段按标准时序，必填状态即时提示。 | 生效后就地更新已放下状态，今天清单按业务结果更新。 |
| [B09 手动归档](../design/index.html#b09-branch-archive) | 确认中展示归档影响。 | 成功后相关行收起，焦点退回父行或分区，历程仍可定位。 |
| [B10 删除空分支](../design/index.html#b10-branch-delete-empty) | 确认中显示真实目标和范围。 | 校验并删除成功后局部移除该行，焦点回到相邻可用项。失败保留在原处。 |
| [B11 取消归档](../design/index.html#b11-branch-unarchive) | 可见性和额度条件在确认中展示。 | 成功后恢复默认树中的可见性，保留原状态。可以前往对应分支定位。 |
| [B12 重新开始](../design/index.html#b12-branch-restart) | 选择重开后按条件显示恢复或移动说明。 | 成功后更新分支状态和待办分组。需先移动时保留当前状态和操作上下文。 |

## 4. 实现验收

1. 每页在 1440 px 和 390 px 各走一次实际操作。明暗版应具有相同的触发、焦点和时序。检查长文本、快速滚动、浏览器返回和涉及遮罩的窄屏滚动。
2. 复测添加 → 完成 → 回执 → 历程，以及当天撤销。待办、提交、计数与目标节点最终一致。分别测试失败、连点完成、跨日锁定和快速切换筛选。
3. 分组树逐一核对名称、展开和更多三处触发。移动、收尾及归档后回到真实分支位置。两步收尾中返回上一步，原先选择仍可见。
4. 对柱状或时间树类的首次反馈，验收真实前后变化和完全静态的结果。筛选、缩放和返回过程中保留当前窗口的阅读锚点。
5. 模拟校验失败、保存失败、慢备份和 V2 慢网络，界面准确显示进行中或失败。检查连续选择两个备份文件时使用最后选择的结果。复测认证切换、重发计时、失效链接和进入本机入口。
6. 在系统减少动效模式下重复核心链路。动作直接达到终态，键盘可以操作并看见焦点，状态播报以真实成果为准。
