> **已归档（2026-11-21），由 [页面与交互规格](../../UI-PAGES.md) 取代。** 12 页清单、阶段标注、首页分段形态与「线的规则」均已并入现行文档；本稿的备份阶段与加密口径与已定结论冲突，不再作为实现依据，只用于查早期布局与取舍。

> 依据：`docs/FRAMEWORK.md` v0.4（对象模型 / 四个一级入口 / 页面清单 / 功能编号）。全站延展规则、首页诊断与提示词等过程稿已移出仓库归档，本文只保留结构结论。
>
> 本方案只定义结构、层级、尺寸与状态，不绑定视觉方向；深色与纸墨两套都能落进同一骨架（见第 17 节）。
>
> **修订记录（v2）**：补入登录、注册、找回三页（V2）；修正"全站没有登录/未登录两套骨架"的旧判断；全清单标注 MVP / V1 / V2；新增第 2.4 节可见性与拦截矩阵、第 18 节 V2 对既有骨架的影响。

## 1. 结论：12 个页面

| # | 页面 | 路由 | 层级 | 阶段 | 一句话职责 |
|---|---|---|---|---|---|
| P0 | 首页（营销） | `/` | 独立 | MVP | 两秒讲清"分支—提交"，然后送进 `/today` |
| P1 | 今天 | `/today` | 一级 | MVP | 回答"我现在做什么" |
| P2 | 分支 | `/branches` | 一级 | MVP | 回答"我手上在推什么" |
| P3 | 分支详情 | `/branches/:id` | 二级 | MVP | 一条分支的全部工作：目标、待办、提交、子分支 |
| P4 | 历程 | `/history` | 一级 | MVP | 回答"我走成了什么样"（时间树） |
| P5 | 年轮 | `/history/:year` | 二级 | V1 | 一年一次的结构回顾，不是放大版周报 |
| P6 | 我的 | `/me` | 一级 | MVP | 徽章、数据与账号的总入口 |
| P7 | 设置 | `/settings` | 二级 | MVP | 外观、字号、密度、注解；V2 增账号与同步分区 |
| P8 | 数据与备份 | `/data` | 二级 | MVP（导出/导入；快照与异地备份 V1） | 导出、导入、恢复前副本、明文 JSON 备份 |
| P9 | 登录 | `/auth/login` | 独立（无外壳） | V2 | 冷启动入口：把本机数据归属到账号 |
| P10 | 注册 | `/auth/signup` | 独立（无外壳） | V2 | 建立账号，承接当前设备数据 |
| P11 | 找回与重置 | `/auth/recover` | 独立（无外壳） | V2 | 找回凭证；三步同页，不拆页 |

**不计为页面的全局层（8 类）**：快速添加、待办详情、提交详情、搜索/命令面板、确认对话框、首次引导、站内登录提示（V2）、同步冲突与设备浮层（V2）。桌面端是 480px 侧滑或 480–640px 浮层，移动端是全屏 sheet；**不新增第七种弹层语言**。

**为什么是 12 个**：四个一级入口是产品已定的信息架构；分支详情内容量必须独立成页；年轮、设置、数据与备份各有独立主语与阅读节奏；认证三页在 V2 承担"冷启动 + 换设备 + 清缓存"三种无上下文场景，必须是可深链的独立路由。

### 1.1 登录/注册：独立成页（与用户倾向一致）

**结论：登录、注册、找回都做独立页面，路由 `/auth/*`，不套应用外壳，不做在主页面上的弹窗。**

理由（按重要性排序）：

1. **冷启动没有上下文。** 从分享链接、换设备、清缓存后回来的人，落地时既没有左导航也没有数据；弹窗压在一块空页面上，用户看不出"登完会去哪"。
2. **独立路由才能承载 `?next=`。** 深链被拦、点"同步"被拦、点分享被拦，三种来源的落点不同；独立页可以原样带回去，弹窗做不到。
3. **账号页需要完整的失败与合规区。** 凭证错误、网络错误、条款、权限说明、二次验证，这些内容塞进 480 弹窗会变成滚动地狱；独立页有正常的纵向节奏。
4. **与"本地优先"不冲突。** 独立页只是入口，不是门槛：不登录仍可用全部 MVP 功能（见 2.4）。

**站内触发登录用轻量提示，不用弹窗**：在需要登录的行内显示一条 12px 提示 + 文字链「登录」（例如"开启同步需要登录"），点击跳到 `/auth/login?next=<当前路由>`。全站不出现"登录后继续"的遮罩。

### 1.2 对旧判断的修正

旧版写的"全站没有登录/未登录两套骨架"在 V2 不再成立，修正为：

> **V2 起存在账号，但不新增第二套应用骨架。** 认证页是唯一的"无外壳"页面组；应用内 7 个页面在未登录与已登录下骨架完全一致，差异只落在两个位置：`/me` 的身份行、`/settings` 的账号与同步分区。拦截只发生在 4 个功能入口上，不发生在页面上（2.4）。

## 2. 骨架与公共尺寸

### 2.1 应用外壳

| 项 | 桌面（≥1024） | 移动（<768） |
|---|---|---|
| 顶栏 | 64px，左字标 14/600 + 面包屑 12px；右侧「记一笔」40px 描边按钮 + 搜索图标 | 56px，左返回/标题，右搜索 |
| 左导航 | 252px，4 项，行 40px，选中 = 6% 底 + 1px 左沿 | 无，改为底栏 56px 三格（今天 / 分支 / 历程）+ 我的 |
| 内容区 | 左 padding 24，max-width 1180，超出居中 | 全宽，padding 16 |
| 底部状态 | 24px，10px mono：`本地 · 已备份 3 分钟前` | 并入设置页 |
| 全局入口 | `n` 记一笔、`/` 搜索、`g t/g b/g h/g m` 跳转 | 底栏 + 顶栏搜索 |

**不使用悬浮圆角 FAB**：快速添加固定在顶栏右侧（桌面）与底栏右侧（移动），保证页面上永远只有一个实心强调动作。

### 2.2 排版与控件（两套主题共用）

- 字阶：H1 40 / H2 28 / H3 20 / body 15 / 次 13 / 注 12 / mono 11–12。**display 148/96 只允许出现在 `/`**。
- 行高：40、28 用 1.15；20 用 1.35；15 用 1.5；12 用 1.4。
- 间距：4 基线，段间 48，页头下 32，块内 12/16。
- 线宽：0.75 / 1 / 1.5，仅此三档。
- 圆角：控件 2、面板 3、营销 CTA 0、状态点 999。
- 控件：高 40（移动 44），1px 边框，无阴影；每屏最多一个实心按钮。
- 动效：120ms 微反馈、200ms 常规、320ms 每页一次编排；应用内无无限循环。
- 行：40（紧凑 36，移动 44）；表头 36 sticky + 1px 下边线；hover 4%，选中 6% + 1px 强调左沿。

### 2.3 路由与进入路径

```
/                       P0 首页
 ├─ 开始使用 ───────────► /today            （不需要登录）
 └─ 登录（页脚 11px 文字链，V2）──► /auth/login?next=/

/today ──待办行──────────► 待办详情（侧滑，URL 不变）
 ├─ 全部待办 ───────────► /today/all（同页切换视图，非新页面）
 └─ 回顾卡片 ───────────► 回顾面板（侧滑）

/branches ──行──────────► /branches/:id
 ├─ 详情内子分支 ───────► /branches/:childId
 └─ 已归档（V1）───────► /branches?view=archived

/history ──节点──────────► 提交详情（侧滑）
 ├─ 里程碑 ─────────────► 里程碑浮层
 └─ 年份入口 ───────────► /history/:year

/me ──徽章───────────────► 徽章详情（浮层）
 ├─ 数据与备份 ─────────► /data
 ├─ 账号行（V2）────────► /auth/login?next=/me  或  /settings#account
 └─ 设置 ───────────────► /settings

/auth/login ◄──► /auth/signup
   └─ 忘记密码 ─────────► /auth/recover
/auth/recover?token=…    （邮件链接直达第 3 步）

/settings#account /settings#sync（V2，同一页内的分区锚点，不新增路由）
```

返回规则：二级页 ← 回到父页并**保留滚动位置与展开状态**；跨一级入口切换时重置滚动。浏览器后退必须可用（不拦截）。

### 2.4 可见性与拦截矩阵（V2）

| 页面 / 能力 | 未登录 | 已登录 | 拦截行为 |
|---|---|---|---|
| P0 首页 | 可见 | 可见 | 无 |
| P1 今天 / P2 分支 / P3 分支详情 / P4 历程 | 可见、可写 | 可见、可写 | **无**（本地优先，L-01） |
| P5 年轮 | 可见 | 可见 | 无 |
| P6 我的 | 可见；身份行显示"未登录 · 本机数据" | 可见；显示邮箱与同步状态 | 无；账号行文字链到登录 |
| P7 设置 | 可见；账号/同步分区显示 12px 登录提示 | 可见 | 无；点分区内开关时跳登录 |
| P8 数据与备份 | 可见；导出/导入可用 | 同左 | 本机快照与异地备份均按匿名设备工作（V1），不要求登录 |
| P9–P11 认证页 | 可见 | 已登录访问 → 重定向 `next` 或 `/today` | 仅重定向，不显示"已登录"页 |
| 功能：同步开关、设备列表、账号资料 | 不可用 | 可用 | 入口点击 → 登录页，携带 `next` |
| 分享链接（`/?share=`） | 可见 | 可见 | 无 |

**硬拦截页面数为 0**。所有拦截都是"功能级"的，且只发生在四个入口：同步开关、设备管理、异地备份上传、账号资料编辑。这是为了守住"清缓存/换设备后仍能先看到东西、再决定是否登录"。

## 3. P0 首页 `/`（MVP）

**职责**：让人两秒看懂"分支—提交"，相信它真实存在，然后点进去。**形态以定稿图 `design/images/p00-home-light.png` 为准**（2026-11-20 19:33 敲定，793×1983，按 1512 宽折合约 3800px）：分段场景，分支线不贯穿整页。

| 段 | 区块 | 内容 |
|---|---|---|
| 1 | 首屏 | 顶栏（无按钮）、eyebrow、双行标题（"今天"着色）、副文案、两个入口；右侧产品窗（今天清单 + 勾选 + 蓝色回执 + 黄色便签）与右缘注解 |
| 2 | 三块内容，一个工作区。 | 三张功能卡：今天 / 分支 / 历程，各一枚图形 |
| 3 | 分段导航 | 今天 / 分支 / 历程 三项，激活项细线滑到对应项，随滚动追踪当前区块 |
| 4 | 一处放下，沿路找回。 | 左：今日清单卡片；右：历程柱状图卡片；两张独立产品窗 |
| 5 | 沿着分支，找回每一次完成。 | 时间树产品窗：三条一级泳道、分叉与合回、选中节点 |
| 6 | 生活里，处处能用。 | 三张场景卡：做作品 / 跑一公里 / 继续阅读 |
| 7 | 今天就开一页。 | 全页唯一实心 CTA、页脚 1px 与链接 |

**线的规则**：分支线只在单个演示窗内出现，随所在区块结束而收束；区块之间用整幅背景带和标题分隔，**不画从首屏贯穿到页尾的长线，也不跨区块出画重入**。定稿图里首屏的点线止于「已提交」回执，第 4、5 段的线各自独立。"贯穿 4200px 的长线"与"跨屏出画—入画"两种旧说法均作废。
**状态**：静态页，无加载/空态；视频或 Canvas 一律不用。V2 起页脚加一个 11px「登录」文字链，其余不变。
**移动端**：按同一顺序单栏堆叠，删去右缘注解与段内的左右双栏，产品窗左右各裁 24px；分段导航改为横向可滚。
**素材**：文案 9 条、一个 6 节点示例树、零摄影素材。
**去向**：唯一主出口 `/today`；页脚另有 11px 登录链（V2）与 GITHUB 外链（可选）。

## 4. P1 今天 `/today`（MVP）

**职责**：默认落地页；回答"现在做什么"。**长度：一屏到一屏半**，不做长页。

### 版面
桌面：`main 1fr (820) + aside 320`，gap 24；aside 在 <1280 时落到主列下方。移动：单列。

### 区块（自上而下）
1. **页头**（高 96）：`2026 年 11 月 20 日 周四`（12 mono）+ H1「今天」+ 右侧摘要 `3 条 · 2 条逾期`（13 次级）。
2. **快速添加条**：40px 高，1px 框，placeholder「记一件要做的事，可带日期」；聚焦时下沿出现 1px 强调边（不放大、不阴影）。
3. **逾期组**：表头 36px，`逾期 4` + 折叠箭头；>5 条默认折叠；行 40px，checkbox 16px 方框（1px），标题 15，右侧分支路径 12 次级。
4. **今天组**：同上，无表头装饰，仅 12px mono 小标。
5. **无截止日期组**：默认折叠，显示条数。
6. **全部待办**：一行 40px，右箭头；进入后同页切换为全量表格（`/today/all`）。
7. **回顾卡片**（G-01）：仅周六、周日、周一出现；H3 20 + 3 个数字 + 一句数据生成的提问（13，两行截断）。点击开侧滑面板。
8. **右栏**：① 停滞分支（>30 天，最多 5 行，40px，灰点 + 天数）② 最近提交 3 条（11px mono hash + 12px 文案）。

### 交互
- 点 checkbox 立即完成，**不弹框**；行在 200ms 内收合并露出下一条；右下出现 10s 的撤销（仅当天有效）。
- 完成后可选"补一句"：行原地展开一个 1 行输入（40px），失焦保存为提交文案。
- 键盘：`j/k` 移动、`x` 完成、`n` 记一笔、`/` 搜索、`Enter` 打开详情。

### 状态
| 状态 | 表现 |
|---|---|
| 空 | 全新空树：不显示三组；A-01 引导（一句话 + 输入 + 「完成第一条」）；下方一行"先看看示例"（A-02，6 节点预览，顶部 1px 虚线） |
| 加载 | 不用 spinner：三条 40px 占位行，仅左侧 1px 轴线，120ms 后替换 |
| 错误 | 1px danger 左边线的行：13px 原因 + 12px「重试」；不清空已有列表 |
| 只读 | 不适用（今天不展示归档待办） |
| 未登录 | 无差异（V2 下同样可写） |

### 移动端
单列；行 44；底栏 56；快速添加固定底栏上方 56px 全宽；回顾卡片移到最后；右栏两条折叠成"更多"。

### 素材
文案 6 条；数据：今日三组计数、停滞分支、最近 3 条提交；无图像。

## 5. P2 分支 `/branches`（MVP）

**职责**：结构的家。一眼看清三层树、进度与状态，进入详情。**长度：视口内为主**，树超过 20 行时内部滚动。

### 版面
页头 96 + 视图切换（树 / 列表，分段控件 1px 描边）+ 主区。树视图整宽（max 1180）；列表视图表格贴满 1180。

### 区块
1. **页头**：H1「分支」+ 计数 `12 条进行中 · 3 条已合并`（13）+ 右侧唯一实心「新建分支」。
2. **筛选条**（36px）：状态（进行中 / 已合并 / 已放下 / 归档 V1）；排序（手动 V1 / 最近活动）。
3. **树视图**：行 40（紧凑 32，移动 44）；缩进 20px/层；连接线 1px 直角转折；行内 6px 状态方点 + 15px 名称 + 12px `3/7` + 右侧 12px 最近活动；L1/L2 默认展开，L3 折叠；hover 4%，选中 6% + 1px 左沿。
4. **列表视图**：表头 36 sticky（名称 / 层级 / 待办 / 提交 / 最近活动 / 状态），行 40，列间 1px 竖线，无斑马纹。
5. **底部统计条**：1px 上边线；`活跃 12 / 200`、`L1 3 / 7`；接近上限时数字转 warning 色（仅文字）。

### 交互
- 单击行 → 详情；点箭头 → 展开；`⋯`（48 悬停出现）：重命名、移动、新建子分支、收尾、放下、归档、删除。
- 新建分支：480 侧滑（名称 + 父分支 + 目标一句，可选）。
- 移动分支：菜单 → 选择器；非法目标置灰并给 12px 原因（层级/重名/额度）。

### 状态
| 状态 | 表现 |
|---|---|
| 空 | 「先建一条你想推进的线」+ 「新建一级分支」+ 「看示例」 |
| 加载 | 树骨架：L1 三条 + 缩进占位，1px 轴线先出现 |
| 错误 | 同 P1 的错误行语言 |
| 只读 / 受限 | 达到额度：新建禁用 + 12px「已达 L1 上限 7 条，先归档一条」；归档区进入后顶部 24px 灰条 + 「只读」，行不可拖 |
| 未登录 | 无差异 |

### 移动端
树改为单列手风琴，缩进 16px，连接线只在左侧一段；筛选条横滚；统计条移末尾；右上「新建」。

### 素材
文案 8 条；数据：树（≤200 节点）、每节点待办数/提交数/最近日期；无图像。

## 6. P3 分支详情 `/branches/:id`（MVP）

**职责**：一条分支的全部工作与历史。**长度：中长页**（约 2–4 屏），分段堆叠，不用 tab 面板。

### 版面
页头 128 + sticky 二级锚点 36 + 单列 max 820（右侧 320 放进度与元数据，<1280 落到内容后）。

### 区块
1. **页头**：面包屑 12px（每段可点）+ H1 40 + 6px 状态点 + 12px 元信息（创建 / 最近活动 / 层级）；**目标一句话** 15px，点击原地变 40px 单行输入（1px 强调边），Enter 保存，空目标显示 12px 占位；右侧 `收尾`（描边）+ `⋯`（放下 / 归档 / 移动 / 删除）。

## 18. V2 引入账号后，既有骨架怎么变

| 页面 | 改动 | 具体 |
|---|---|---|
| P0 首页 | 微改 | 页脚多一个 11px「登录」文字链；分段结构与各段顺序不变 |
| P1 今天 / P2 分支 / P3 分支详情 / P4 历程 / P5 年轮 | **零改动** | 不出现账号元素；未登录与已登录完全一致 |
| P6 我的 | 微改 | 页头下插入 48px 身份行（未登录/邮箱/同步状态）；设置列表第 5 行改为「账号与同步」；其余区块不动 |
| P7 设置 | 微改 | 左分区从 4 项扩到 6 项（新增 `#account`、`#sync`），右表单宽度与行规格不变 |
| P8 数据与备份 | 加区块 | 现有三段之后插入「异地备份」段（V1，不要求登录） |
| 应用外壳 | 微改 | 底部状态栏的 10px mono 增加同步态：`已同步 2 分钟前` / `仅本机`；顶栏高度与命中区不变 |
| 全局层 | 新增 2 类 | 站内登录提示（行内 12px）、同步冲突/设备浮层（480） |
| 新增页面 | 3 个 | P9 / P10 / P11，均无应用外壳 |

**落位规则**：
- `/me` 的身份行在页头之下、徽章之上，高 48，占满 820 宽；未登录时右侧是「登录」文字链，登录后换成邮箱 + 同步状态，**行高不变**，避免布局跳动。
- `/settings` 的分区顺序固定为：外观 → 数据与备份 → 账号 → 同步 → 提醒 → 关于；账号与同步相邻，因为它们共享同一组凭证状态。锚点用 `#account`、`#sync`，不新增二级路由；设备列表与冲突处理用 480 浮层，避免设置页变成三级结构。
- 所有"需要登录"的入口统一走 `/auth/login?next=<当前路由>`，登录成功原路返回，不回到首页。
