# CommitToDo 组件规格

原图册覆盖 12 个页面与 38 个补充视图和操作状态。组件以已定稿的明暗主题、分组树和工作区公共壳为基线，Web 认证与账号设置采用最新专项稿。下文定义使用范围与交互契约，编号、阶段及每张画稿的入口见页面规格。[设计交接](DESIGN.md) · [页面与状态](UI-PAGES.md) · [视觉、令牌与图形](UI-VISUAL.md) · [首页动效](HOMEPAGE-MOTION.md) · [应用动效](UI-MOTION.md) · [原图册](../design/index.html) · [Web 认证画稿](web-auth/DESIGN.md)

## 共享组件与状态

| 组件 | 交互契约 |
| --- | --- |
| 应用外壳／导航 | 今天、分支、历程、我的四个一级入口。二级页继承上级选中态，面包屑回到真实父页面。本机、离线与备份时间按真实状态显示。移动端用底部一级入口。 |
| 页头／按钮／图标按钮 | 页头承载标题、日期或说明和主操作。主、次、低强调、危险操作的优先级清晰；图标控件有可读名称。默认、悬停、焦点、按下、禁用和处理中都可以辨认。 |
| 输入／行内编辑 | 标签、当前值、可选说明、错误与可用状态。提交失败保留用户输入，支持纠正或重试。保存时以可读文字给结果。 |
| 待办复选框 | 复选框与对应待办名称关联。完成、进入详情、展开分组和待办菜单是独立动作。同一点击只生成一条有效提交。 |
| 分段控件／筛选 | 树／列表切换、状态筛选、时间范围和根／一级分支筛选都有可读当前值。视图以选中的范围及真实数据为准。 |
| 列表／面板 | 共用标题区、内容与行间边界。空状态说明原因并给出一个可用动作；加载使用占位行；局部错误保留已加载数据并明确重试入口。 |
| 身份标记／状态标签 | 身份由名称、归属路径和分支色共同表达。进行中、已合并、已放下、只读、已锁定等状态用文字配合形状或语义色。 |
| 回执／行内提示 | 保存或完成后就地反馈，标出发生的动作。出现与收起各 200 ms，停留 10 s，悬停或聚焦时暂停计时；收起后归档到常驻处（完成类进「最近提交」）。可通过「在历程查看」定位实际提交。撤销仅在写入当日可用，跨零点后改为只读说明。同一位置只保留一条回执，新的替换旧的。失败不进回执，就地显示错误行。完整状态机见[应用动效](UI-MOTION.md)。 |
| 菜单、侧栏、对话框 | 源位置附近的分支菜单；编辑或详情以 480 px 桌面侧栏呈现；确认或选择采用居中对话框。窄屏适配可滚动内容和操作区。[浮层样式](../design/source/layers.css) |

## 分组树与分支操作

分组头用于识别一级方向，子行显示分支名称、直接待办进度、活动日期与状态。进度取当前分支自己的已完成数／总数，空集合显示「暂无待办」。行内展开控件控制可见子树，名称进入 P03，行尾「更多」打开当前分支操作菜单。详情页可复用同一业务动作与其禁用原因。[分组树画稿](../design/index.html#p02-branches) · [12 个分支操作状态](../design/index.html#branch-operations)

| 状态 | 形式与关键表达 | 阶段 |
| --- | --- | --- |
| B01 分支操作菜单 | 按分支标识、权限和状态提供动作。禁用项带可读原因，V1 的置顶、放下与归档按阶段出现。收尾遵循分支详情更多菜单与树右键的入口设计。 | MVP／V1 |
| B02 新建分支 | 右侧栏，一级分支可选预设色相。呈现名称、父级和可选目标。 | MVP |
| B03 新建子分支 | 右侧栏，显示父级、继承色和层级额度，同级重名与不可接收父级给出原因。 | MVP |
| B04 重命名 | 对话框，核对同级唯一性，含已归档分支。 | MVP |
| B05 移动 | 对话框形式的父级选择器，显示不可用原因，包括层级、循环引用、额度、同级重名与状态。移动之前已发生的收尾关系仍按原时间和父级显示。 | MVP |
| B06/B07 收尾 | 首先选择未完成待办去向与历史分支是否留树；仍有未完成待办或选择收起时，加一步确认影响。提交与待办数按真实结果显示，按钮为「确认收尾」，在确认步说明收尾之后不能撤销。 | MVP |
| B10 删除空分支 | 对话框。在整棵相关子树仍进行中、从未产生业务历史时显示可执行入口；其余情况呈现禁用原因。 | MVP |
| B08/B12 放下／重新开始 | 放下原因必填，说明「今天」的未完成待办将如何受影响；重新开始按原截止日期回到正常分组，必要时先提示移动到可接收的父级。 | V1 |
| B09/B11 手动归档／取消归档 | 标明历史与默认树可见性、额度与可用条件。取消归档检查祖先可见性和额度。 | V1 |

## 待办、历程和回顾

| 组件 | 最小数据与行为 | 阶段 |
| --- | --- | --- |
| 快速添加／待办列表 | 题名、稳定标识、所属分支、截止／计划日期和状态。快速添加展示识别结果，可修改。今天依次显示逾期、今天、无截止日期且每条只出现一次，保留全部待办入口。 | MVP |
| 待办详情 | 标题、备注、截止日期、计划日期、所属分支及历史。按状态提供编辑、完成、调整归属、安排到今天或移出今天。 | MVP |
| 提交行、回执与提交详情 | 使用同一提交标识，显示文案、时间、原始分支与同分支前后有效节点。当地写入日内可纠错；跨自然日锁定。撤销需恢复待办、作废记录并重算受影响的统计。 | MVP |
| 时间范围与直达 | 顶部一个范围控件含「近 90 天／今年／全部」，分支筛选另设。普通访问沿用上次范围与筛选，提交、徽章或搜索直达临时展开目标，保留原偏好。 | MVP |
| 时间树与图例 | 日期按比例布局。轨道含创建、分出、合回、最后有效提交等时点，读出当前可见状态。图例同步标明线型、圆形提交、空心汇合点与菱形里程碑。邻近事件可聚合并展开查看。 | MVP |
| 里程碑列表／详情／新建 | 同一里程碑可从列表或图中开放详情。创建支持准确日期或仅年月，提供可选备注；里程碑不计入最近提交日期。 | MVP |
| 首次引导与示例 | 完成第一条真实待办后回执可直达历程。独立示例明确标注，可退出；实际数据、统计和备份独立运行。 | MVP |
| 周回顾面板 | 显示统计区间、有效提交、分布、停滞与一条回顾问题。周六／日预览本周，周一看同区间正式版。 | MVP |
| 全局搜索 | 查分支、待办、有效提交、里程碑。结果标明类型与归属，支持打开详情或定位历程，可选择包含归档历史。 | V1 |
| 月回顾、年轮与分享 | 月回顾聚焦结构变化。年轮与分享共用按年统计，日期截点、空未来月份和支持编辑的当年总结可读。分享预览 4:5，以泳道缩略为主体，默认隐藏待办标题及分支名，分支名可选择显示。 | V1 |

## 我的、备份与账号

| 组件 | 状态与行为 | 阶段 |
| --- | --- | --- |
| 徽章入口与卡片 | 「我的」提供已获徽章及对应事件的历程入口；徽章墙按类别与获授时间显示状态，当时统计取授予快照。 | MVP 已获列表；V1 徽章墙／详情 |
| 偏好表单 | 主题三档、树密度两档、注解三档。字号 13／15／17 px 自 V1 起提供，与树密度独立；注解只读一处开关。 | MVP，逐阶段增项 |
| 本机备份与文件导出 | 显示备份时间、摘要和「立即备份」。自动快照保留最近 7 份，全量导出 JSON 含 `schemaVersion`。 | MVP |
| 从文件恢复 | 选择文件、校验结果、摘要、替换确认。确认后先备份当前数据再整体替换，校验或写入失败时保留现有数据。若此前有数据，可下载最近一次成功恢复前的副本。 | MVP |
| 快照恢复、异地备份 | 快照恢复显示快照时间和计数。异地备份使用明文 JSON，按匿名设备归档，提供上传／下载。 | V1 |
| 危险操作确认 | 清空等操作显示受影响对象、备份入口与明确的确认输入；按业务条件启用。 | MVP 起 |
| 认证壳、表单与找回 | 顶栏始终提供「打开本机工作区」。桌面共用左表单、右侧时间树和提交回执构图，窄屏保留单列表单。填写邮箱、检查邮箱和设置新密码用同一组步骤指示。登录渠道按 V2 实施约定。 | V2 |
| 站内登录提示与账号设置 | 未登录时在相关功能处就地提供登录和注册。已登录时显示邮箱、状态与退出入口。退出确认复用对话框，文案说明本机数据保留与同步停止。 | V2 |
| 设备与冲突记录 | 设备层标出当前设备和可用管理动作。冲突记录呈现来源、修改与查看入口，策略按 V2 方案。 | V2 |
| 帮助与常见问题 | 多组可阅读内容，解释界面与业务概念，从「我的」进入。 | V2 |

## 交互验收

- 主操作、名称链接、展开控件和菜单可独立聚焦。模态打开后焦点进入、关闭后回到触发处；长内容用可滚动区，关键按钮与关闭入口可触达。图标和图表有可读标签。
- 验收浅色、深色和窄屏。选择、只读、禁用、告警和焦点用语义、文字及形状共同区分。移动端历程保留日期、分支、事件与合回关系。
- 减少动效设置下保留状态变化、勾选、定位和详情。完成与收尾、文件校验与恢复、登录与本机工作区分别走通实际操作链路。
- 画稿中带数字的是示例状态。路由、权限、可用阶段与数据来源都用真实产品条件校验。[页面规格](UI-PAGES.md)
