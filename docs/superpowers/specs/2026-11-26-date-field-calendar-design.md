# 日期字段改为月历弹层

## 意图

记一笔里的截止日期仍是浏览器自带日期框，左右只能一天天加减，点文字常常打不开日历。改成可读的日期按钮：常见的今天、明天、下周五不用开日历；要挑某一天时，左右切月，点一天写回 `YYYY-MM-DD`。

## 目标

- 触发器显示 `11月27日 周五`，不再露出原生日期框和浏览器日历图标。
- 按钮下方三个快捷项：今天、明天、下周五。点一下即写入并保持弹层关闭。
- 点触发器打开月历：左右切月，点一天写入并关闭。
- 写入值仍是 `YYYY-MM-DD`。记一笔、待办详情、引导页继续用同一个 `DateField`。

## 非目标

- 不改快捷添加的解析规则，不改库存的日期格式。
- 不做时间选择、不做日期区间、不做年视图。
- 不引入日期组件包或图标库。

## 失败样子

- 快捷项或月历里出现写死的中文、色值或字号。
- 弹层是第二层居中模态，把记一笔整页盖住。
- 引导页可以选到今天之前。

## 约束

- 文案只进 `zh-CN.ts`。`t()` 没有插值，月份和星期用数字加文案片段拼出来。
- 样式只用 `design/tokens.css` 的变量。图标沿用 `svg-icon` 自绘，不引图标库。
- 月历格子、星期、下周五的计算放在 `core`，不调用 `Date.now()` / `new Date()` 取当前时刻。测试传固定日期。
- `DateField` 仍在 `ui`，不依赖 `data` / `stores`。

## 方案

1. **自绘月历弹层（选用）。** 锚定在触发器下方，空间不够时翻到上方。Esc 和点外面关闭，焦点回到触发器。不新依赖。
2. **`react-day-picker`。** 弹层、快捷项、令牌和文案仍要自己写，比自绘更绕。
3. **整套组件库。** 和令牌、自绘图标、文案表冲突，排除。

## 已定行为

- 去掉 `+` / `−` 和原生 `<input type="date">`。
- 快捷项三处都有。引导页的 `min` 仍生效：早于 `min` 的日期和快捷项不可选。
- `disabled` 时触发器和快捷项都不可用，弹层打不开。
- 非法 `value` 用 `fallbackDate` 显示，用户点选后才通过 `onChange` 写回。
- 一周从周一开始。今天在当月格子里有标记，已选日高亮。切月不改值，只有点某一天才写入。
- 方向键在格子间移动，Enter 选定，Esc 关闭。

## 留给实现时定的

- **下周五**：当前周的下一周的周五。周从周一开始。今天若是周四，明天是本周五，下周五是再过一周的周五，不和「明天」重复。今天若是周五，下周五是 7 天后。
- 显示文案拆成 `date.monthMark`、`date.dayMark` 和 `date.weekday.mon` … `date.weekday.sun`，数字由代码拼接。
- 月历数学放在 `core/calendar.ts`（或 `clock.ts` 旁的纯函数），配单元测试。组件测试不做，仓库的 `unit` 项目不测 React。
- 弹层用绝对定位，不用现有的居中 `Dialog`。窄屏（390）时格子不撑破记一笔面板。
