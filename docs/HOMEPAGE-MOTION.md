# CommitToDo 首页动效规范

本页是营销首页的实施与验收依据。页面结构见 [页面设计](UI-PAGES.md)，应用内反馈与令牌见 [视觉规范](UI-VISUAL.md)。

首屏「查看示例」定位公开的工作区展示区。顶栏「登录」进入 `/auth/login`，「打开工作区」与页尾「打开 CommitToDo」进入 `/today`。示例首次入视播放一次；播放结束后，悬停主标题或工作区路径可重播。「查看示例」点击时也会重播并定位，供键盘与触屏操作。离开视口冻结示例时钟，返回后续播。

视觉基准是 2026 年 11 月 20 日 19:33 敲定的两张首页图：`p00-home-light.png`（793×1983，浅色）与 `p00-home-dark.png`（同尺寸，逐像素对应的暗色版）。章节顺序遵循这两张图，「一处放下，沿路找回。」之后依次是今日清单与柱状图、分支卡、时间树，再到生活场景和页尾。每个区块自带独立演示窗，分支线随区块结束而收束，**不贯穿整页，也不跨区块出画重入**。[浅色定稿](../design/images/p00-home-light.png) · [暗色定稿](../design/images/p00-home-dark.png)

## 与上一轮动效核对的对照

把官网观察、旧 CommitToDo 原型的实测和这版定稿的设计决定逐项对应。旧研究中的官网采样范围和未核实的镜头仍以原记录为准。下表的原型交互均指本地 CommitToDo 演示。过程稿（提示词、原型与选稿图）已移出仓库归档，正文只保留结论。

| 旧方向 | 旧稿动作与实测 | 当前定稿如何处理 |
| --- | --- | --- |
| **20 Notion · 贴纸工作间** | 8 秒循环中，「今天／分支／历程」轮换，便签和回执移动，工作台始终展示今天。明暗版复测均可暂停，暂停期间标题播放时间冻结。浅色、暗色原型均已复测。 | 承接高亮字块、黄色便签和蓝色回执。标题固定在「今天。」；便签和回执只在示例勾选时动。约 1.4 秒的一次播放，完成后由标题或工作区路径悬停重播。 |
| **01 Codex · 蓝紫光场** | 浅色原型的示例默认已勾选。复测取消后回执隐去，再勾选回执出现。联动发生在复选框和回执之间。 | 承接亲手勾选就能看到回执的机制。新示例从未完成开始，增加对同一条时间树节点的创建、撤销和直达。 |
| **12 Stripe · 流动色带** | 旧演示的回执小卡周期漂浮，冷暖色带给界面分层；评审发现任务与分支归属的因果偏弱。 | 只取任务和回执之间的前后层次。小卡响应勾选抬升一次，点线从源任务出发，归属由回执里的分支名和实际节点说明。 |
| **15 Xiaomi · 跑道摄影长镜头** | 旧研究采样到横向轮播和细进度线，本地演示有横移镜头与手动选择。评审认为它更适合健康分支案例。 | 用作动作幅度的取舍依据。动感集中于卡片内部的一小段进度线。 |
| **21 Framer · 画布折面** | 「按分支／按日期」切换可实际改变可见内容。 | 延续控件和图形状态一致的要求。回执定位到目标分支，节点选择打开同一记录的详情。「页面调研」合回时的亮点按已定稿时间树重新编排。 |

本轮用 Chromium 复测了旧 Notion 的两种主题。滚动从 0 到 751 px 时，三张功能卡中第一张的 CSS 视口时间线都停在约 32%。这版章节动画采用一次性入视触发，用普通时钟把动作播完；静态内容始终可读。验收以动作实际发生和前后画面可区分为准。

## 从一笔勾选，到树上一个节点

整页跟着示例待办「完成线框初稿」走。点一下，黄色便签像被指尖碰了一下，蓝色点线从任务行接到「已提交」回执。用户继续往下看，时间树会把「工作 / 产品设计」的分支关系画出来。「完成线框初稿」在 **11 月 20 日 16:42** 落成一个高亮节点。首屏、回执和历程始终指向同一条示例记录。

### 首屏 · 1.4 秒，一次播放

| 时间 | 画面与触发 |
| --- | --- |
| 0–200 ms | 「今天。」背后的蓝色底纹从左往右擦出，标题、按钮和工作台在入场前已经可读。 |
| 200–600 ms | 工作台保持静止，焦点留给任务行。示例待办暂为未完成。 |
| 600–720 ms | 蓝色勾选出现，任务行切到浅蓝选中态。左侧黄色便签以贴角为轴轻摆约 3°，在 240 ms 内回到定稿角度，旁边的两笔手绘短线随之显出一次。 |
| 720–1,040 ms | 一小段蓝色点线从任务所在行往右描，画到回执边缘。 |
| 990–1,190 ms | 回执抬升约 6 px、由半透明变清楚，在原位停住，显示任务名、所属分支和时间。 |
| 1,190–1,400 ms | 画面留在两张定稿所示的完成状态；悬停主标题或工作区路径可重播。 |

以工作台卡片作为自动播放目标，首次有约 45% 进入视口时开始。播放中悬停不重置计时；完成后，指针进入主标题或工作区路径时从头重播。点击「查看示例」会重播并定位。自动播放只改变示例状态。用户主动勾选时立即接管，120 ms 内给出勾选反馈，省去开场和等待。示例状态、提示信息和时间树节点同步更新。动画只负责解释这个变化。

## 各区块动效

| 区块 | 定稿动作 | 触发和时长 |
| --- | --- | --- |
| 三张功能卡 | 「今天」的图标勾一笔，「分支」从根处分出两段，「历程」三个节点依次亮起。动作集中在图标，卡面、正文和边界稳定。 | 整组首次入视，卡间错开 60 ms，单卡约 160 ms。悬停或键盘聚焦时仅反馈对应图标一次。同一帧撞上入场和聚焦时合并。 |
| 分段导航 | 激活项下方的细线滑到对应项；在下方内容中追踪当前阅读区块。 | 点击或键盘激活时 160 ms。用户主动选择才定位页面，浏览器后退和自然滚动按原本方式工作。 |
| 今日清单与柱状图 | 右侧五根柱从图底依次长到定稿高度。左侧清单保留可扫读的稳定列表，手动触发才出现短勾选反馈。 | 图表首次入视，单根 160 ms，间隔 32 ms，整组约 288 ms。 |
| 分支列表 | 展开时三角标旋转，关联子行显出，父行和标签保持定位。聚焦行只在当前行加描边或浅色底。 | 点击、触控或键盘激活示例树的展开控件，约 180 ms。 |
| 时间树 | 先看见日期与泳道名称；父线往右描，随后子线从实际创建处岔出。「页面调研」合回父线时，交汇处短亮一次；「产品设计」保持展开，最后让已提交的同名节点出现一圈高亮。 | 首次入视触发一次，约 620 ms。通过回执直达时，先定位已有图形，随后用约 320 ms 强调目标支线和节点。 |
| 三张生活场景卡 | 对应颜色的细轨迹前进一个节点，轮廓弧线同步微亮，光度随后回到定稿。卡片本身保持位置。 | 首次入视轻扫一轮，后续在指针悬停或触摸时只反馈目标卡，约 200 ms。 |
| 页尾行动按钮 | 指针悬停或键盘聚焦时，箭头向前移约 2 px，按钮色阶轻抬。 | 约 120 ms。 |

### 时间树的分叉、合回与选中

- 日期按真实的时间比例摆放。样例范围为 11.06 至 11.20，11.13 在中点。工作、健康、生活各占一条一级泳道。工作下的子分支沿用自己的同色系。「页面调研」较早岔出，在 11.13 合回工作线；「产品设计」随后岔出，通向 11.20 的示例提交。
- 实线交代结构，圆点代表提交，菱形代表里程碑。完成节点的细环是选中状态，底下的支线颜色继续代表分支。两种主题的节点形状、位置与含义一致。停滞虚线沿用功能框架的条件，首屏右侧的短点线只负责把任务和回执连起来。
- 回执本身可点，操作名称为「在历程查看：完成线框初稿」。它定位时间树、展开「产品设计」、选中唯一的示例节点并显示日期、任务名和分支。用户直接点图中的节点也能打开相应详情，关闭后焦点回到该节点。选中信息同时以边框和文字表达。
- 示例完成后出现唯一节点，撤销示例时回执与节点一起撤销。页面滚动、主题切换和重复查看保留当前状态。真实用户从「打开工作区」进入自己的数据，第一次使用从空根分支开始。示例的勾选、悬停重播与真实工作台数据分别运行。[功能框架 A-01、A-02、E-01、F-01 至 F-03](FRAMEWORK.md)

## 明暗、播放和窄屏

- **两套主题同一动作。** 浅色用墨蓝选中线和暖黄便签。暗色保留定稿的蓝灰底，图标沿用冰蓝、薄荷绿、淡紫的局部点色，时间树沿用工作橙、健康蓝、生活金。用颜色体现状态的动作只发生在笔画、边框和节点上，整屏亮度保持稳定。
- **首屏播放与重播。** 自动播放结束后停在完成态，不循环。悬停主标题或工作区路径重播，不移动页面；点击「查看示例」重播并定位，键盘和触屏均可操作。右上角「登录」进入独立认证页，「打开工作区」进入本机工作区。离开首屏冻结计时，返回继续原状态。若用户在演示启动前直达时间树，则呈现静态完成示例，回到首屏后可悬停重播或点击「查看示例」重播。
- **减少动效。** 使用系统减少动效设置时，首屏直接显示稳定完成画面，时间树和柱形图直接出现完整静态内容。勾选、撤销、展开、焦点和详情照常可用，页内定位立即到达。关键结果通过文字和控件状态同步反馈。
- **桌面和窄屏。** 390 px 下先保证任务行和回执完整可见，回执可在工作台下方落位，点线缩短。时间树允许在图表容器内横向查看，泳道名称及可见焦点便于跟踪。触控和键盘都能选节点，页面保持自然纵向滚动。
- **动效节奏。** 首页有自己的四档节奏，与应用页面不同，不要互相套用：微反馈 120 ms（页尾箭头、主动勾选）、组件级 160–200 ms（功能卡图标、分段导航、生活场景卡）、组合段 288 ms（五根柱 + 32 ms 间隔）、单段编排 620 ms（时间树首次入视）。首屏 1.4 s 的整段表演是唯一例外，只播一次。进场缓动用 `--ease-enter: cubic-bezier(.2,0,0,1)`，退出用 `--ease-exit`。应用页面的 320 ms 上限不适用于本页，两者的计时表分开维护。[应用动效](UI-MOTION.md) · [视觉规范](UI-VISUAL.md)

## 实现后的验收

| 验收场景 | 通过条件 |
| --- | --- |
| 正常首屏 | 「今天。」、勾选、便签、点线和回执按顺序出现。正文和「打开工作区」全程可用，自动表演只发生一次。 |
| 自动播放与重播 | 离开视口时冻结并在返回后续播；完成后悬停主标题或工作区路径从头播放，播放中悬停不会重置；点击「查看示例」重播并定位。 |
| 手动链路 | 用户手动勾选立即接管；选择回执后定位到「工作 / 产品设计」的「完成线框初稿」。反复查看仍只有一条提交。 |
| 滚动走查 | 正常动效下从章节外滚入，图标、柱形或分支线如期开始，起止画面有可见变化，同一区块自动播一次。快速滚动、直接跳到历程和返回页面都能看到完整图形。关闭动画增强后直接显示完整静态内容。 |
| 明暗、窄屏、减少动效 | 在两主题的桌面与 390 px 下走一遍操作，再开系统减少动效复查。触控和键盘都能查看节点，正文、回执、焦点与主要入口均可见。 |

状态为**动效设计定稿**。上述时序和交互是后续实装的验收依据。
