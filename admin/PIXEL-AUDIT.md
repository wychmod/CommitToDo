# 管理端像素级视觉核对

本文档是 [`PAGES.md`](PAGES.md) 的视觉核对补充：`PAGES.md` 定义信息架构、字段与 390/1440 降级规则，本文档只记录「画稿值 / 实测值 / 差值」与修复结果，不改变字段口径。视觉真源仍是 [`docs/visuals/`](docs/visuals/)。

- 范围：总览（含图表与空态）、数据表列表、表详情、行详情抽屉、行编辑与确认、审计列表与回退、鉴权三态
- 宽度：1440 与 390
- 本轮新增：总览图表区、行编辑/确认、审计回退、功能使用与使用漏斗
- 截图：[`docs/pixel-audit/`](docs/pixel-audit/)，共 27 张

## 1. 复现参数

| 项 | 1440 组 | 390 组 |
| --- | --- | --- |
| 视口 | 1440×900（长页另用 1440×1240） | 390×844（长页另用 390×1600） |
| DPR | 1 | 1 |
| 滚动位置 | 0,0 | 0,0 |
| 滚动条 | 截图时 `--hide-scrollbars`；测量时 `document.documentElement.style.scrollbarWidth='none'` | 同左 |
| 设备模拟 | 桌面 | CDP `Emulation.setDeviceMetricsOverride`（mobile, touch） |
| 数据 | DEV fixture：`?fixture=ready` / `forbidden` / `unverified` / `signed_out`；`&drawer=1` 自动开抽屉；`&metrics=empty` 空态 | 同左 |
| 开发服务 | `npm run dev -- --port 5175 --strictPort` | 同左 |

fixture 只在 `import.meta.env.DEV` 下生效，生产构建不改变行为；实现见 [`src/lib/fixture.ts`](src/lib/fixture.ts)。截图与测量脚本在页面内读取 `getBoundingClientRect()` 与 `getComputedStyle()`，尺寸取 1 位小数，颜色取浏览器计算后的 `rgb()` / `rgba()`。

**画稿值口径**：取 `docs/visuals/README.md`、`prompts-core.md`、`prompts-audit-access.md` 中写明的数值；不对 PNG 逐像素取样。画稿是 AI 生成的示意图，暗像素扫描会因抗锯齿与压缩噪声给出错误边界。
