# 管理端像素级视觉核对

本文档是 [`PAGES.md`](PAGES.md) 的视觉核对补充：`PAGES.md` 定义信息架构、字段与 390/1440 降级规则，本文档只记录“画稿值 / 实测值 / 差值”与修复结果，不改变字段口径。视觉真源仍是 [`docs/visuals/`](docs/visuals/)。

- 修复提交：`29b8ddb`（`fix(admin): 按画稿对齐管理端像素规格`）
- 截图与本文档随后续 `docs(admin)` 提交入库
- 范围：总览、数据表列表、表详情、行详情抽屉、审计列表、鉴权三态（未登录 / 非白名单 / 邮箱未验证）
- 宽度：1440 与 390

## 1. 复现参数

| 项 | 1440 组 | 390 组 |
| --- | --- | --- |
| 视口 | 1440×900 | 390×844 |
| DPR | 1 | 1 |
| 滚动位置 | 0,0 | 0,0 |
| 滚动条 | 截图时 `--hide-scrollbars`；测量时 `document.documentElement.style.scrollbarWidth='none'` | 同左 |
| 设备模拟 | 桌面 | CDP `Emulation.setDeviceMetricsOverride`（mobile, touch） |
| 数据 | DEV fixture，`?fixture=ready` / `forbidden` / `unverified` / `signed_out` | 同左 |
| 开发服务 | `npm run dev -- --port 5175 --strictPort` | 同左 |

fixture 只在 `import.meta.env.DEV` 下生效，生产构建不改变行为；实现见 [`src/lib/fixture.ts`](src/lib/fixture.ts)。

测量脚本在页面内读取 `getBoundingClientRect()` 与 `getComputedStyle()`，坐标与尺寸取 1 位小数；颜色取浏览器计算后的 `rgb()` / `rgba()`。截图文件见 [`docs/pixel-audit/`](docs/pixel-audit/)。

**画稿值口径**：取 `docs/visuals/README.md`、`prompts-core.md`、`prompts-audit-access.md` 中写明的数值；不对 PNG 逐像素取样。画稿是 AI 生成的示意图，暗像素扫描会因抗锯齿与压缩噪声给出错误边界（例如分割线被识别到 y=40）。
