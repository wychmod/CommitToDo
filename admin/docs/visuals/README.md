# CommitToDo 管理站 · 浅色桌面画稿

2026 年 11 月 22 日。15 张画稿均由内置 ImageGen 生成。视觉沿用[浅色首页](../../../design/images/p00-home-light.png)的纸白、冰蓝、墨蓝字色与细边框。登录页保留斜置 C 标记和分支合流意象。登录后的页面用蓝色标记选中与操作，少量薄荷绿和暖金区分就绪状态。

共用顶栏以指标总览稿为准。品牌与「总览」「数据表」「审计」靠左排列，当前账号和退出操作在右侧。页内主操作使用蓝色，表格以细边框和浅蓝选中行区分状态。
